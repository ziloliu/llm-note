# 第七章 LCD（液晶显示器）— 原理与接口分类 笔记

---

## 一、LCD 概述

### 1.1 什么是 LCD

```
LCD = Liquid Crystal Display（液晶显示器）

当前最主流的显示技术：
  → 电脑显示器、手机屏幕、平板电脑、电视
  → 几乎所有电子设备的交互式信息展示都使用 LCD
  → 已全面取代早期的 CRT 显示器
```

### 1.2 CRT 显示器（已淘汰）

```
CRT = Cathode Ray Tube（阴极射线管）

特点：
  → 体积大、厚度大（后面有长长的"尾巴"）
  → 类似早期的老式电视机（大头电视）
  → 理论上亮度更高、颜色饱和度更高

被淘汰的原因：
  → 体积太大，不便于携带
  → 无法用于便携式设备（笔记本、手机、平板）
  → 液晶技术进步后，LCD 的显示效果已完全满足需求
  → LCD 的核心优势：薄、轻、省电
```

## 二、LCD 接口驱动方式分类

### 2.1 按驱动方式分类

```
LCD 显示屏的驱动/接口连接方式：

  ① MCU 模式        ← 常用
  ② RGB 模式        ← 常用
  ③ SPI 模式
  ④ VSYNC 模式
  ⑤ MDDI 模式
  ⑥ DSI 模式

用得最多：MCU 模式和 RGB 模式
```

### 2.2 两种核心模式概述

```
MCU 模式和 RGB 模式底层原理相同：
  → 都使用 RGB（红绿蓝）三原色表示每个像素的颜色
  → 都需要显存（GRAM）存储所有像素的颜色数据
  → 区别在于 GRAM 放在哪里
```

## 三、RGB 颜色表示原理

### 3.1 光学三原色（加法三原色）

```
RGB = Red（红）、Green（绿）、Blue（蓝）

本质：
  → 红光、绿光、蓝光三种不同频率的电磁波
  → 人眼中的感光细胞恰好能捕获这三种频率的光
  → 以此三种颜色作为基准，混合表示所有颜色

混合规则（加法混合）：
  → 不同颜色的光叠加 → 频率叠加 → 表现出新的颜色
  → 所有光等比例混合 → 白光
  → 用三棱镜分光 → 七色彩虹（白光分解）

常见混合示例：
  R + G = 黄色（Yellow）
  R + B = 紫色/品红（Magenta）
  G + B = 青色/蓝绿（Cyan）
  R + G + B = 白色（White）
  全无 = 黑色（无光）

为什么叫"加法"三原色：
  → 光的混合是叠加
  → 光越多 → 越亮
  → 全部叠加 → 白光（最亮）
```

### 3.2 美术三原色（减法三原色）

```
美术三原色：品红（Magenta）、黄（Yellow）、青（Cyan）
           即 CMY（不是传统认为的"红黄蓝"）

本质：
  → 颜料/涂料反射光的原理与发光不同
  → 白光照射到颜料表面
  → 颜料吸收（减去）特定颜色的光
  → 剩余颜色的光反射回来 → 人眼看到对应颜色

颜色与吸收关系：
  品红颜料 = 吸收绿光 → 反射 R + B → 看到品红
  黄色颜料 = 吸收蓝光 → 反射 R + G → 看到黄色
  青色颜料 = 吸收红光 → 反射 G + B → 看到青色

混合规则（减法混合）：
  → 品红 + 黄 = 吸收绿光和蓝光 → 只剩红光 → 红色
  → 品红 + 青 = 吸收绿光和红光 → 只剩蓝光 → 蓝色
  → 黄 + 青 = 吸收蓝光和红光 → 只剩绿光 → 绿色
  → 品红 + 黄 + 青 = 三种光全吸收 → 黑色

为什么叫"减法"三原色：
  → 混合颜料 = 叠加吸收
  → 颜料越多 → 吸收越多 → 越暗
  → 全部混合 → 黑色（全吸收）
```

### 3.3 两种三原色对比

| 对比项 | 光学三原色（RGB） | 美术三原色（CMY） |
|--------|------------------|------------------|
| 基准颜色 | 红、绿、蓝 | 品红、黄、青 |
| 混合方式 | 加法（光叠加） | 减法（吸收叠加） |
| 全部混合 | 白色 | 黑色 |
| 应用场景 | 发光设备（显示器、电视） | 反射设备（印刷、绘画） |
| 原理 | 发出不同颜色的光 | 吸收特定颜色的光 |

## 四、显存（GRAM）

### 4.1 什么是 GRAM

```
GRAM = Graphic RAM（图形随机存取存储器）
     = 显存

本质：
  → 一个存储矩阵
  → 存储液晶屏上每一个像素点的颜色数据
  → 每个像素点用 RGB 数据表示颜色

示例：
  320 × 240 分辨率的屏幕：
    → 共有 320 × 240 = 76800 个像素点
    → 每个像素点需要一组 RGB 数据
    → 如果使用 RGB565（16 位）格式：
      → 总显存 = 76800 × 2 字节 = 153600 字节 ≈ 150 KB
```

### 4.2 GRAM 的位置决定了驱动模式

```
关键问题：GRAM（显存）放在哪里？

  方案一：放在液晶驱动器内部
    → MCU 模式
    → 主机通过接口发送命令和数据
    → 液晶驱动器内部处理并存储

  方案二：放在主机侧（显卡）
    → RGB 模式
    → 主机（CPU/GPU）处理所有图像数据
    → 直接输出 RGB 数据流给液晶

  两种模式的核心区别：GRAM 的归属位置不同
```

## 五、MCU 模式

### 5.1 基本原理

```
MCU 模式：
  → GRAM 集成在液晶驱动器（LCD 模块）内部
  → 主机（MCU/单片机）只需发送命令和数据
  → 液晶驱动器负责将数据写入 GRAM 并驱动显示

工作流程：
  ① MCU 通过接口向液晶驱动器发送命令（如设置坐标）
  ② MCU 通过接口向液晶驱动器发送颜色数据
  ③ 液晶驱动器接收数据，写入内部 GRAM
  ④ 液晶驱动器读取 GRAM 数据，驱动屏幕显示

主机侧的工作：
  → 只需要发送命令和数据
  → 不需要集成显存
  → 功能简单，适合 MCU/单片机

液晶驱动器的工作：
  → 接收命令和数据
  → 内部集成 GRAM 存储像素数据
  → 将数据转换为驱动像素的信号
  → 驱动屏幕显示
```

### 5.2 与 FSMC 的结合

```
MCU 模式下的液晶控制 → 可以用 FSMC 实现！

原理：
  → GRAM 本质是一个存储器
  → 液晶驱动器的接口本质上就是存储器接口
  → FSMC 可以扩展外部存储器
  → 因此 FSMC 可以控制 LCD

具体做法：
  → 将 LCD 模块的接口连接到 FSMC 的地址线、数据线、控制线
  → LCD 的 RS（寄存器选择）连接 FSMC 的 A10
  → 通过不同的地址区分写命令和写数据
  → CPU 像访问存储器一样访问 LCD

优势：
  → 利用 FSMC 的自动协议转换
  → 无需手动编写通信协议
  → 速度快（并行传输）
  → 配置简单
```

### 5.3 MCU 模式的特点

```
优势：
  → 主机侧（MCU）工作简单
  → 只需发送命令和数据
  → 不需要集成显存
  → 适合单片机等资源有限的设备
  → 可以用 FSMC 简化控制

劣势：
  → 液晶驱动器处理能力有限
  → 显示速度相对较慢
  → 适合静态图片或简单画面
  → 动态画面或大屏幕可能不够流畅

适用场景：
  → 嵌入式设备的小屏幕显示
  → 静态信息展示（菜单、参数、文字）
  → 简单图形界面
  → 分辨率较低的屏幕（如 320×240、480×320）
```

## 六、RGB 模式

### 6.1 基本原理

```
RGB 模式：
  → GRAM 集成在主机侧（显卡/GPU）
  → 主机（CPU/GPU）处理所有图像数据
  → 直接输出每个像素的 RGB 数据流给液晶
  → 液晶只负责接收和显示，不做数据处理

工作流程：
  ① CPU/GPU 处理图像数据，写入显卡的显存（GRAM）
  ② 显卡从 GRAM 读取数据
  ③ 显卡产生 RGB 数据流 + 同步信号（行同步、帧同步）
  ④ RGB 数据流直接传输给液晶面板
  ⑤ 液晶面板直接驱动显示

主机侧的工作：
  → CPU/GPU 完成所有图像处理
  → 显卡集成 GRAM（显存）
  → 产生 RGB 数据和同步信号
  → 工作量大但处理能力强

液晶面板的工作：
  → 只负责接收 RGB 数据流
  → 直接驱动像素显示
  → 不做数据处理和存储
```

### 6.2 显卡的组成

```
显卡的核心组成：

① GPU（Graphics Processing Unit，图形处理单元）
   → 专门处理图像数据的处理器
   → 类似于专用的 CPU
   → 大规模并行计算能力强
   → 适合处理海量像素数据

② 显存（GRAM）
   → 存储所有像素的颜色数据
   → 容量越大 → 可支持更高分辨率和更复杂的图像

③ LCD 控制器
   → 从显存读取数据
   → 产生 RGB 数据流和同步信号
   → 输出给液晶面板
```

### 6.3 独立显卡 vs 集成显卡

```
集成显卡：
  → GPU 集成在 CPU 内部
  → 显存可能与内存共享
  → 性能较弱，功耗低
  → 适合日常办公和轻度图形处理

独立显卡：
  → GPU 独立芯片
  → 专用显存（GDDR5/GDDR6 等）
  → 性能强大，功耗高
  → 适合游戏、3D 渲染、AI 计算等

应用场景：
  → 大型游戏 → 需要高性能独立显卡
  → AI 训练/推理 → 显卡的并行计算能力
  → 视频剪辑/3D 建模 → 显卡加速
  → 日常办公 → 集成显卡即可
```

### 6.4 RGB 模式的特点

```
优势：
  → 液晶面板只负责显示，响应快
  → 适合大屏幕、高分辨率
  → 适合动态画面（视频、动画）
  → 主机侧处理能力强

劣势：
  → 需要专用的显卡/LCD 控制器
  → 需要集成显存
  → 主机侧资源需求大
  → 不适合资源有限的单片机

适用场景：
  → 电脑显示器
  → 电视
  → 高分辨率、高刷新率的屏幕
  → 需要流畅动态画面的场景
```

## 七、MCU 模式 vs RGB 模式对比

| 对比项 | MCU 模式 | RGB 模式 |
|--------|---------|---------|
| GRAM 位置 | 液晶驱动器内部 | 主机侧（显卡） |
| 主机工作 | 发送命令和数据 | 完成所有图像处理 |
| 液晶工作 | 接收数据 + 存储 + 驱动显示 | 只接收 + 驱动显示 |
| 显示速度 | 相对较慢 | 快 |
| 适合画面 | 静态/简单画面 | 动态/复杂画面 |
| 主机资源 | 需求少（适合单片机） | 需求大（需要显卡） |
| 典型应用 | 嵌入式小屏幕 | 电脑显示器/电视 |
| 控制方式 | 可用 FSMC | 需要专用 LCD 控制器 |
| 屏幕大小 | 小屏幕 | 大屏幕 |
| 分辨率 | 较低（320×240 等） | 较高（1920×1080 等） |

## 八、MCU 模式下 LCD 的控制方式

### 8.1 控制流程

```
MCU 控制 LCD 显示的基本流程：

  ① 初始化 LCD 驱动器
     → 发送初始化命令序列
     → 配置显示参数（分辨率、颜色格式等）

  ② 设置显示区域
     → 发送命令设置 GRAM 的写入坐标
     → 指定要写入的像素位置（行列地址）

  ③ 写入颜色数据
     → 将 RGB 颜色数据写入 GRAM
     → 每写入一个数据，GRAM 地址自动递增
     → 连续写入多个像素的颜色数据

  ④ 液晶驱动器自动刷新显示
     → 从 GRAM 读取数据
     → 驱动对应像素点显示颜色
```

### 8.2 FSMC 控制 LCD 的地址映射

```
FSMC 连接 LCD 模块：

  写命令：访问地址 0x6C00_0000（A10 = 0 → RS = 0 → 命令）
  写数据：访问地址 0x6C00_0800（A10 = 1 → RS = 1 → 数据）

示例：
  // 写命令
  *(volatile uint16_t *)0x6C000000 = 0x002C;  // 发送命令码

  // 写数据
  *(volatile uint16_t *)0x6C000800 = 0xF800;  // 写入红色 RGB565

效果：
  → CPU 访问特定地址
  → FSMC 自动转换为 LCD 接口的通信协议
  → LCD 驱动器接收命令或数据
  → 数据写入内部 GRAM
  → 屏幕显示对应颜色
```

## 九、关键概念速查

| 概念 | 说明 |
|------|------|
| LCD | 液晶显示器（Liquid Crystal Display） |
| CRT | 阴极射线管显示器（已淘汰） |
| RGB | 红绿蓝三原色（Red Green Blue） |
| GRAM | 显存（Graphic RAM），存储像素颜色数据 |
| MCU 模式 | GRAM 在液晶驱动器内部，MCU 只发命令和数据 |
| RGB 模式 | GRAM 在主机侧（显卡），直接输出 RGB 数据流 |
| 光学三原色 | RGB，加法混合，全混合 = 白光 |
| 美术三原色 | CMY（品红、黄、青），减法混合，全混合 = 黑色 |
| 加法三原色 | 光的叠加，光越多越亮 |
| 减法三原色 | 颜料的吸收叠加，颜料越多越暗 |
| GPU | 图形处理单元，专门处理图像数据的处理器 |
| 显卡 | GPU + 显存 + LCD 控制器，RGB 模式的核心 |
| 集成显卡 | GPU 集成在 CPU 内部，性能较弱 |
| 独立显卡 | 独立 GPU + 专用显存，性能强大 |
| RS | 寄存器选择信号，连接 FSMC A10 |
| RGB565 | 16 位颜色格式（5 位红 + 6 位绿 + 5 位蓝） |
| 像素点 | 屏幕上的最小显示单元 |
| 分辨率 | 屏幕像素点的数量（如 320×240、1920×1080） |

## 十、常见问题

| 问题 | 解答 |
|------|------|
| MCU 模式和 RGB 模式的核心区别？ | **GRAM 的位置**不同：MCU 在液晶内部，RGB 在主机侧 |
| 嵌入式单片机用哪种模式？ | **MCU 模式**，资源需求少，可用 FSMC 控制 |
| 电脑显示器用哪种模式？ | **RGB 模式**，需要显卡输出数据流 |
| 为什么 MCU 模式显示较慢？ | 液晶驱动器处理能力有限，每帧需要通过接口传输数据 |
| GRAM 是什么？ | 显存，存储所有像素颜色数据的存储矩阵 |
| 光学三原色全混合是什么？ | **白色**（加法混合） |
| 美术三原色全混合是什么？ | **黑色**（减法混合，所有光被吸收） |
| FSMC 怎么控制 LCD？ | LCD 的 GRAM 视为 SRAM 类型，通过不同地址区分命令和数据 |
| RGB565 格式占多少位？ | **16 位**（5 红 + 6 绿 + 5 蓝） |
| 独立显卡为什么贵？ | 高性能 GPU 芯片 + 大容量高速显存 |
| 为什么叫减法三原色？ | 颜料越多 → 吸收的光越多 → 越暗 → 最终黑色 |
