# 第六章 FSMC 控制器 — 概述与基本原理 笔记

---

## 一、为什么需要 FSMC

### 1.1 片内存储资源的局限

```
STM32 片内存储资源：

  SRAM：64 KB
  Flash：512 KB

与个人电脑对比：
  → 片内存储资源非常有限
  → 对于大量数据处理场景远远不够

典型资源不足的场景：
  → 图像处理（高分辨率液晶屏显示）
  → 每个像素点都需要存储数据
  → 分辨率越高、屏幕越大 → 需要的内存越大
  → 64 KB SRAM 完全不够用
```

### 1.2 解决方案：存储器扩展

```
STM32 提供了 FSMC 模块来解决存储资源不足的问题：

  FSMC = Flexible Static Memory Controller
       = 灵活的静态存储器控制器

核心功能：
  → 动态、灵活地扩展外部存储器
  → 让 CPU 像访问片内存储一样访问外部存储芯片
  → 对外提供地址线、数据线和控制信号
  → 内部自动完成通信协议的转换
```

## 二、FSMC 支持的存储器类型

### 2.1 支持的存储器

```
FSMC 可管理的存储器类型：

① SRAM（静态随机存取存储器）
   → 速度最快，容量较小

② PSRAM（伪静态随机存取存储器）
   → P = Pseudo（伪）
   → 接口与 SRAM 完全相同（可用 SRAM 的方式控制）
   → 容量比 SRAM 大很多（性能介于 SRAM 和 DRAM 之间）

③ NOR Flash（或非门 Flash）
   → 按字节读取，可执行代码

④ NAND Flash（与非门 Flash）
   → 按页/块读写，容量大

⑤ PC 卡（PC Card）
   → 一般不使用
```

### 2.2 关键限制：只支持静态存储器

```
FSMC 的核心限制：
  → 只支持 Static（静态）存储器
  → 不支持需要动态刷新的存储器

不支持的存储器：
  ❌ DRAM（需要定期刷新）
  ❌ SDRAM（同步动态 RAM）
  ❌ DDR / DDR2 / DDR3 / DDR4（双倍速率 SDRAM）

注意：
  → SDRAM 中的 S 是 Synchronous（同步），不是 Static（静态）
  → SDRAM 本质是 Dynamic RAM → 需要动态刷新 → FSMC 不支持
  → 不能用电脑内存条（DDR）通过 FSMC 扩展到 STM32
```

## 三、SDRAM 与 DDR（扩展知识）

### 3.1 SDRAM 概念

```
SDRAM = Synchronous Dynamic Random Access Memory
      = 同步动态随机存取存储器

S = Synchronous（同步）
  → 数据访问有同步时钟控制
  → 支持突发传输（Burst Transfer）

D = Dynamic（动态）
  → 底层用电容存储，需要定期刷新

核心优势：突发传输（Burst Transfer）

  普通传输：
    → 每次访问都要先发地址，再读写数据
    → 访问连续地址 → 每次都要重新发地址 → 效率低

  突发传输：
    → 只发一次起始地址
    → 后续连续读写多个数据，地址自动递增
    → 不需要每次都重新发地址 → 效率大幅提升
```

### 3.2 SDRAM 如何解放 CPU

```
普通内存访问：
  CPU 发出地址 → 等待内存响应 → 读写数据 → CPU 继续等待...
  → CPU 大部分时间都在等待内存（被"占用"）

SDRAM 同步访问：
  ① CPU 发出地址和控制信号
  ② SDRAM 内部锁存器保存地址和控制信息
  ③ CPU 释放总线 → 去做其他事情
  ④ SDRAM 自行完成读写操作
  ⑤ 完成后通知 CPU → CPU 再来取数据

  → CPU 被"解放"了，可以同时处理其他任务
  → 系统整体效率大幅提升
```

### 3.3 DDR 的演进

```
DDR = Double Data Rate SDRAM
    = 双倍速率 SDRAM

原理：
  → SDRAM 只在时钟上升沿采集数据
  → DDR 在上升沿和下降沿都采集数据
  → 同一时钟频率下，数据传输速率翻倍

发展路线：
  SDRAM → DDR → DDR2 → DDR3 → DDR4 → DDR5

  → 当前电脑主流使用 DDR4 / DDR5
  → 本质都是 SDRAM 的进阶版本
  → 全部需要动态刷新 → FSMC 不支持
```

## 四、FSMC 工作原理

### 4.1 核心原理

```
FSMC 的本质：
  → 将 AHB 总线上的数据访问操作
  → 转换为外部存储器的通信协议
  → 控制外部存储器的读写时序

工作流程：
  CPU 发出地址 → AHB 总线 → FSMC 接收
  → FSMC 将 AHB 事务转换为外设通信协议
  → 通过地址线、数据线、控制信号驱动外部存储器
  → 完成数据的读写

对 CPU 的效果：
  → CPU 看起来就像在访问一段更大的内存空间
  → 无需关心底层通信协议的细节
  → 直接用地址访问即可
```

### 4.2 功能框图
![[Pasted image 20260906123432.png]]
```

三大组成部分：
  ① AHB 总线接口 → 接收来自 CPU/DMA 的访问请求
  ② 存储控制器 → 将 AHB 事务转换为外设通信协议
     ├── NOR Flash / PSRAM 控制器
     └── NAND Flash / PC 卡控制器
  ③ 外设接口 → 地址线、数据线、控制信号输出到外部存储器
```

## 五、NOR Flash / PSRAM 控制器

### 5.1 功能说明

```
NOR Flash / PSRAM 控制器可以控制：
  → NOR Flash
  → SRAM
  → PSRAM（伪静态 RAM，接口与 SRAM 完全相同）

支持的模式：

  模式           说明
  ────────────────────────────────────────
  异步模式       无同步时钟，靠控制信号时序驱动读写
  同步模式       有同步时钟，支持突发传输

  AHB 数据宽度：8 / 16 / 32 位均可
  外设数据宽度：8 / 16 位（不支持 32 位外部存储器）

注意：
  → SRAM 和 ROM 只支持异步读写模式
  → 不支持同步模式
  → PSRAM 可能支持同步模式（具体看芯片型号）
```

### 5.2 异步 vs 同步

```
异步模式（SRAM/ROM 使用）：
  → 没有同步时钟信号
  → 靠读使能(NOE)、写使能(NWE)等控制信号的时序来驱动
  → FSMC 只在读写操作时产生驱动时钟
  → 时钟频率 = HCLK / 分频系数

同步模式（PSRAM 部分支持）：
  → 有同步时钟信号（CLK）
  → 支持突发传输
  → 可提高连续访问的效率
```

## 六、外设接口引脚详解

### 6.1 引脚分类

```
FSMC 外设接口引脚分为四类：

① NOR Flash / SRAM 专用信号
② 公用信号（地址线 + 数据线 + 读写控制）
③ NAND Flash 专用信号
④ PC 卡专用信号
```

### 6.2 NOR Flash / SRAM 专用信号

```
信号      引脚       全称                    功能
───────────────────────────────────────────────────────
NE[4:1]  —         Chip Enable             片选信号（4 路）
                                            低电平有效
                                            选中对应的外部存储器

NADV     —         Address Valid           地址有效信号
                                            低电平有效
                                            指示当前总线上是有效地址

NBL[1:0] —         Byte Lane               字节选择信号
  NBL0              Lower Byte Lane         低字节使能
  NBL1              Upper Byte Lane         高字节使能
                                            用于 16 位数据中选择高/低字节

CLK      —         Clock                   同步时钟信号
                                            仅同步模式使用
```

```
NBL 信号详解：

  16 位数据总线（D[15:0]）传输 16 位数据：
  ┌────────┬────────┐
  │ 高 8 位 │ 低 8 位 │
  │ D[15:8]│ D[7:0] │
  └────────┴────────┘
     ↑         ↑
   NBL1=0    NBL0=0
   高字节    低字节
   使能      使能

  → 如果只需访问低字节：NBL0 = 0, NBL1 = 1
  → 如果只需访问高字节：NBL0 = 1, NBL1 = 0
  → 如果访问整个 16 位：NBL0 = 0, NBL1 = 0
```

### 6.3 公用信号（所有外设共用）

```
信号        引脚          全称              功能
───────────────────────────────────────────────────────
A[25:0]    26 根地址线   Address            地址总线
                                              26 根 → 可寻址 2^26 = 64M 个单元

D[15:0]    16 根数据线   Data               数据总线
                                              16 位并行传输

NOE        —            Output Enable       读使能信号
                                              低电平有效
                                              使能外部存储器的数据输出
                                              等效于"读使能"

NWE        —            Write Enable        写使能信号
                                              低电平有效
                                              使能数据写入外部存储器

NWAIT      —            Wait                等待信号
                                              外部存储器忙时拉低
                                              指示 FSMC 需要等待
```

```
NOE 和 NWE 的理解：

  NOE（Output Enable = 输出使能）：
    → 让外部存储器"输出"数据
    → 外部存储器输出数据 = 我们读取数据
    → 因此 NOE 本质上就是"读使能"

  NWE（Write Enable = 写使能）：
    → 让外部存储器"接收"数据
    → 外部存储器接收数据 = 我们写入数据
    → 因此 NWE 就是"写使能"
```

### 6.4 NAND Flash 专用信号

```
信号      功能
──────────────────────────────────────
NCE      NAND Flash 片选信号（低有效）
INT      NAND Flash 中断信号

→ 用于控制 NAND Flash 存储器
→ 一般不常用
```

### 6.5 PC 卡专用信号

```
信号      功能
──────────────────────────────────────
INTR      PC 卡中断信号
NCE       PC 卡片选信号
...

→ 用于控制 PC 卡设备
→ 一般不使用
```

## 七、数据宽度转换

### 7.1 问题背景

```
AHB 总线数据宽度：8 / 16 / 32 位（CPU 可传输任意宽度）
外部存储器数据宽度：8 / 16 位

两者宽度可能不一致 → FSMC 需要做数据宽度转换
```

### 7.2 转换规则

```
情况一：AHB 宽度 > 外设宽度（拆分）

  示例：AHB 32 位 → 外设 8 位

  ┌────────────────────────────┐
  │   32 位数据（4 字节）       │
  │  Byte3 │ Byte2 │ Byte1 │ Byte0 │
  └────────────────────────────┘
       ↓ 拆分
  → 第 1 次传输：Byte0（8 位）
  → 第 2 次传输：Byte1（8 位）
  → 第 3 次传输：Byte2（8 位）
  → 第 4 次传输：Byte3（8 位）

情况二：AHB 宽度 < 外设宽度（填充/对齐）

  示例：AHB 8 位 → 外设 16 位

  ┌──────────┐
  │ 8 位数据  │    只占用外设的低字节或高字节
  └──────────┘    另一字节空闲
       ↓
  → 数据放在低 8 位，高 8 位空闲（或反之）
  → 由 NBL 信号控制选择高/低字节

注意事项：
  → 宽度不匹配可能导致数据不一致
  → 建议尽量保持 AHB 宽度与外设宽度一致
  → 后续会详细讲解具体处理方式
```

## 八、FSMC 存储器映射

### 8.1 地址空间分配

```
FSMC 将外部存储器映射到 STM32 的地址空间：

  Block 3（0x6000_0000 ~ 0x7FFF_FFFF）：
    → FSMC Bank 1：NOR Flash / PSRAM / SRAM（256 MB）
    → FSMC Bank 2：NAND Flash（256 MB）

  Block 4（0x8000_0000 ~ 0x9FFF_FFFF）：
    → FSMC Bank 3：NAND Flash（256 MB）
    → FSMC Bank 4：PC Card（256 MB）

  Block 5（0xA000_0000 ~ 0xBFFF_FFFF）：
    → FSMC 寄存器地址空间
```

### 8.2 Bank 划分

```
Bank = 区（存储分区）

  Bank   地址范围                扩展设备            大小
  ──────────────────────────────────────────────────────
  Bank 1  0x6000_0000 ~ 0x6FFF_FFFF  NOR Flash/PSRAM/SRAM  256 MB
  Bank 2  0x7000_0000 ~ 0x7FFF_FFFF  NAND Flash            256 MB
  Bank 3  0x8000_0000 ~ 0x8FFF_FFFF  NAND Flash            256 MB
  Bank 4  0x9000_0000 ~ 0x9FFF_FFFF  PC Card               256 MB

效果：
  → CPU 访问 0x6000_0000 ~ 0x6FFF_FFFF 时
  → FSMC 自动将访问请求转换为 NOR Flash/SRAM 的通信协议
  → 数据通过地址线、数据线传输到外部存储器
  → CPU 感觉就像在访问片内内存一样
```

### 8.3 Bank 1 的子分区

```
Bank 1（NOR Flash / PSRAM / SRAM）进一步分为 4 个子区：

  子区      片选信号    地址范围                  大小
  ──────────────────────────────────────────────────
  Bank1-1   NE1        0x6000_0000 ~ 0x63FF_FFFF  64 MB
  Bank1-2   NE2        0x6400_0000 ~ 0x67FF_FFFF  64 MB
  Bank1-3   NE3        0x6800_0000 ~ 0x6BFF_FFFF  64 MB
  Bank1-4   NE4        0x6C00_0000 ~ 0x6FFF_FFFF  64 MB

→ 最多可接 4 片 NOR Flash / SRAM 芯片
→ 每片由独立的片选信号（NE1~NE4）控制
→ 通过不同的地址区间访问不同的芯片
```

## 九、FSMC 引脚与 GPIO 复用

### 9.1 引脚数量

```
FSMC 使用的引脚数量：

  → 26 根地址线（A[25:0]）
  → 16 根数据线（D[15:0]）
  → 控制信号若干（NE, NOE, NWE, NBL, NADV, CLK, NWAIT...）

  → 总共需要大量 GPIO 引脚
  → 这些引脚都是 GPIO 的复用功能（Alternate Function）
```

### 9.2 引脚映射

```
FSMC 引脚与 GPIO 的对应关系：

  → FSMC 的地址线、数据线、控制信号
  → 映射到 STM32 的特定 GPIO 引脚上
  → 需要将 GPIO 配置为复用推挽输出（AF_PP）模式
  → 具体引脚映射关系见数据手册

注意：
  → FSMC 使用了大量 GPIO 引脚
  → 使用 FSMC 时，这些引脚不能再用作普通 GPIO
  → 需要合理规划引脚资源
```

## 十、FSMC 工作流程总结

### 10.1 读数据流程

```
CPU 读取外部 SRAM 数据：

  ① CPU 发出读地址（如 0x6800_0000）
  ② 地址通过 AHB 总线传到 FSMC
  ③ FSMC 判断地址属于哪个 Bank/子区
  ④ FSMC 拉低对应片选信号（NE）
  ⑤ FSMC 拉低读使能信号（NOE）
  ⑥ 地址通过 A[25:0] 地址线发给外部 SRAM
  ⑦ 外部 SRAM 根据地址输出数据到 D[15:0]
  ⑧ FSMC 读取数据，通过 AHB 总线返回给 CPU
  ⑨ FSMC 释放片选和读使能信号
```

### 10.2 写数据流程

```
CPU 写入外部 SRAM 数据：

  ① CPU 发出写地址和写入数据
  ② 地址和数据通过 AHB 总线传到 FSMC
  ③ FSMC 判断地址属于哪个 Bank/子区
  ④ FSMC 拉低对应片选信号（NE）
  ⑤ 地址通过 A[25:0] 地址线发给外部 SRAM
  ⑥ 数据通过 D[15:0] 数据线发给外部 SRAM
  ⑦ FSMC 拉低写使能信号（NWE）
  ⑧ 外部 SRAM 锁存地址和数据，完成写入
  ⑨ FSMC 释放片选和写使能信号
```



## 十一、NOR Flash / SRAM 控制器特性

### 11.1 支持的操作模式
![[Pasted image 20260906123629.png]]
![[Pasted image 20260906123655.png]]
```
对照数据手册（第 19 章 19.5.2）：

  模式        操作    AHB 宽度    外设宽度    SRAM/ROM    PSRAM
  ────────────────────────────────────────────────────────────
  异步模式    读       8/16/32    8/16       ✅ 支持      ✅ 支持
  异步模式    写       8/16/32    8/16       ✅ 支持      ✅ 支持
  同步模式    读        —          —         ❌ 不支持    ⚠️ 部分
  同步模式    写        —          —         ❌ 不支持    ⚠️ 部分

关键结论：
  → SRAM 和 ROM 只支持异步读写模式
  → PSRAM 可能支持同步模式（具体看芯片手册）
  → 外部存储器数据宽度支持 8 位和 16 位（不支持 32 位）
  → AHB 总线宽度支持 8 / 16 / 32 位
```

### 11.2 时钟配置

```
FSMC 的驱动时钟：
  → 来源于 HCLK（AHB 总线时钟）
  → 可配置分频系数
  → FSMC 只在读写操作时产生时钟
  → 空闲时不产生时钟 → 节省功耗

配置要点：
  → 需要在 RCC 中开启 FSMC 时钟
  → 根据外部存储器的速度配置合适的时序参数
```

## 十三、关键概念速查

| 概念 | 说明 |
|------|------|
| FSMC | 灵活的静态存储器控制器，用于扩展外部存储器 |
| 静态存储器 | SRAM、ROM、Flash、PSRAM，不需要动态刷新 |
| 动态存储器 | DRAM、SDRAM、DDR，需要定期刷新，FSMC 不支持 |
| PSRAM | 伪静态 RAM，接口同 SRAM，容量更大 |
| SDRAM | 同步动态 RAM（S=同步，D=动态），需要刷新 |
| DDR | 双倍速率 SDRAM，在上升沿和下降沿都采集数据 |
| 突发传输 | 只发一次起始地址，后续连续读写多个数据 |
| NOR Flash | 或非门 Flash，按字节读取，可执行代码 |
| NAND Flash | 与非门 Flash，按页/块读写，容量大 |
| Bank | FSMC 的存储分区（Bank 1~4） |
| NE[4:1] | 片选信号，低电平有效，选中对应外部存储器 |
| NOE | 读使能信号（Output Enable），低电平有效 |
| NWE | 写使能信号（Write Enable），低电平有效 |
| NBL[1:0] | 字节选择信号，控制高/低字节使能 |
| NADV | 地址有效信号，低电平有效 |
| NWAIT | 等待信号，外部存储器忙时拉低 |
| A[25:0] | 26 根地址线，可寻址 64M 个存储单元 |
| D[15:0] | 16 根数据线，16 位并行传输 |
| HCLK | AHB 总线时钟，FSMC 时钟来源 |
| Bank 1-1 ~ Bank1-4 | NOR Flash/SRAM 的 4 个子区，各有独立片选 |

## 十四、常见问题

| 问题 | 解答 |
|------|------|
| FSMC 能接电脑内存条吗？ | **不能**。内存条是 DDR（动态），FSMC 只支持静态存储器 |
| SDRAM 中的 S 是 Static 吗？ | **不是**。S = Synchronous（同步），D = Dynamic（动态） |
| FSMC 支持 SRAM 吗？ | **支持**，SRAM 属于静态存储器，使用异步模式 |
| FSMC 数据线有多宽？ | **16 位**（D[15:0]），外部存储器不支持 32 位 |
| 最多能接几片外部存储器？ | Bank 1 有 **4 个子区**（NE1~NE4），最多接 4 片 |
| 什么是 PSRAM？ | 伪静态 RAM，接口同 SRAM，容量比 SRAM 大 |
| NOE 是什么？ | 读使能信号（Output Enable），低电平有效 |
| NBL 有什么用？ | 16 位数据中选择高字节或低字节 |
| 为什么要引入 FSMC？ | 片内 SRAM 仅 64KB，图像处理等场景不够用，需要扩展 |
| DDR 和 SDRAM 什么关系？ | DDR 是 SDRAM 的进阶版，双倍速率传输 |
| FSMC 的时钟从哪来？ | HCLK（AHB 总线时钟），可配置分频系数 |
| 突发传输是什么？ | 只发一次地址，后续连续读写多个数据，提高效率 |
