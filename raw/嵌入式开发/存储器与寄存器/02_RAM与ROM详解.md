# 第五章 存储器和寄存器 — RAM 与 ROM 详解 笔记

---

## 一、RAM（随机存取存储器）

### 1.1 RAM 基本概念

```
全称：Random Access Memory（随机访问/存取存储器）

核心特点：
  → 可读可写（既能存又能取）
  → 随机访问（给任意地址，直接读写）
  → 易失性（掉电数据丢失）

"随机"的含义：
  → 不是"随机"的"随机"
  → 而是"任意"的意思
  → 随便给一个地址，都可以直接对该地址进行读或写
  → 不需要像磁带那样顺序查找
```

### 1.2 RAM 分类

```
RAM
├── SRAM（Static RAM，静态随机存取存储器）
│   → 只要保持上电，数据就能稳定保存
│   → 不需要额外的刷新操作
│
└── DRAM（Dynamic RAM，动态随机存取存储器）
    → 即使上电，也需要定期刷新才能保持数据
    → 必须不停地"动态"刷新
```

## 二、SRAM（静态随机存取存储器）

### 2.1 存储原理

```
底层结构：六晶体管双稳态触发器电路（6T 结构）

基本原理：
  → 由 6 个 MOS 管组成双稳态触发器
  → 类似于之前学过的锁存器/触发器结构
  → 输入数据后，只要不断电（VCC 和 GND 保持通路）
  → 存 0 → 自动锁定为 0
  → 存 1 → 自动锁定为 1
  → 无需任何额外操作即可保持数据

为什么叫"静态"？
  → 数据一旦写入，只要保持上电就能稳定保存
  → 不需要像 DRAM 那样不停地刷新
  → 状态是"静态"稳定的
```

### 2.2 特点

| 特性 | 说明 |
|------|------|
| 刷新 | **不需要**刷新操作 |
| 速度 | **快**（触发器直接翻转） |
| 成本 | **高**（每个单元 6 个晶体管） |
| 集成度 | **低**（结构复杂，芯片面积大） |
| 容量 | **小**（单颗芯片容量有限） |
| 功耗 | 相对较高 |

### 2.3 应用场景

```
典型应用：CPU 高速缓存（Cache）

为什么用 SRAM 做缓存？

  CPU 速度极快 ←→ 内存（DRAM）速度相对慢
  
  如果 CPU 直接访问 DRAM 内存 → 效率低
  
  解决方案：在 CPU 和内存之间加高速缓存
  ┌─────┐     ┌────────────┐     ┌──────────┐
  │ CPU │ ←→  │ L1/L2/L3   │ ←→  │   内存    │
  │     │     │ Cache(SRAM)│     │  (DRAM)   │
  └─────┘     └────────────┘     └──────────┘
       ← 快速访问 →    ← 较慢但容量大 →

  → 将经常访问的数据放入缓存
  → CPU 直接从缓存读取 → 速度快
  → 如果数据不在缓存中 → 再去访问内存 → 稍慢
```

## 三、DRAM（动态随机存取存储器）

### 3.1 存储原理

```
底层结构：1 个 MOS 管 + 1 个电容（1T1C 结构）

基本原理：
  → 利用电容的充放电特性存储数据
  → 电容充电（有电荷）→ 表示 1
  → 电容放电（无电荷）→ 表示 0

  与 SRAM 对比：
  SRAM → 6 个晶体管 / 每位
  DRAM → 1 个晶体管 + 1 个电容 / 每位
  
  → 结构简单得多
  → 成本低得多
  → 集成度高得多
```

### 3.2 为什么需要刷新

```
电容的物理特性带来的问题：

① 自然放电
   → 即使不读写，电容中的电荷也会缓慢泄漏
   → 存储的 1 会慢慢变成 0

② 电荷吸收
   → 相邻电路可能干扰
   → 存储的 0 可能慢慢变成 1

解决方法 → 定期刷新：
  → 读取每个单元的电容电量
  → 电量 > 满电量的 1/2 → 判定为 1 → 重新充满电
  → 电量 < 满电量的 1/2 → 判定为 0 → 放电清零
  → 重新写回正确的值
  → 保证数据不丢失

为什么叫"动态"？
  → 数据不是静态稳定的
  → 电容状态时刻在"动态"变化（放电/充电）
  → 必须通过动态刷新来维持数据正确性
```

### 3.3 特点

| 特性 | 说明 |
|------|------|
| 刷新 | **需要**定期刷新 |
| 速度 | 相对**较慢**（电容充放电需要时间） |
| 成本 | **低**（每个单元仅 1T + 1C） |
| 集成度 | **高**（结构简单，单位面积容量大） |
| 容量 | **大**（单颗芯片容量可达数 GB） |

### 3.4 应用场景

```
典型应用：电脑内存条

  电脑内存容量需求大（通常 8GB / 16GB / 32GB ...）
  → SRAM 集成度低，容量做不大，成本太高
  → DRAM 集成度高，容量大，成本低
  → 所以电脑内存使用 DRAM

  常见类型：
  → DDR SDRAM（Double Data Rate Synchronous DRAM）
  → DDR4 / DDR5 内存条
```

## 四、SRAM vs DRAM 对比

### 4.1 核心对比

| 对比项 | SRAM | DRAM |
|--------|------|------|
| 存储单元 | 6 晶体管触发器 | 1 晶体管 + 1 电容 |
| 刷新 | 不需要 | 需要定期刷新 |
| 速度 | **快** | 较慢 |
| 成本 | **高** | 低 |
| 集成度 | 低 | **高** |
| 容量 | 小 | **大** |
| 功耗 | 较高 | 较低 |
| 典型用途 | CPU Cache | 内存条 |

### 4.2 设计取舍思想

```
这是一个经典的工程设计取舍：

追求速度（SRAM）：
  → 结构复杂（6T 触发器）
  → 成本高
  → 集成度低
  → 容量做不大

追求容量（DRAM）：
  → 结构简单（1T + 1C）
  → 成本低
  → 集成度高
  → 但速度慢，还需要刷新

实际应用 → 两者配合：
  CPU ← SRAM（Cache）← DRAM（内存）
  兼顾速度和容量
```

### 4.3 单片机 vs 个人电脑

```
┌─────────────────────────────────────────────────────────┐
│  STM32 单片机：                                          │
│    → 内部 RAM 直接使用 SRAM                              │
│    → 容量小（如 STM32F103C8T6 → 20 KB）                  │
│    → 不需要 DRAM，SRAM 速度更快                           │
│    → 结构简单，无需额外缓存                               │
├─────────────────────────────────────────────────────────┤
│  个人电脑（PC）：                                         │
│    → 内存使用 DRAM（DDR4/DDR5）                          │
│    → 容量大（8GB / 16GB / 32GB ...）                     │
│    → CPU 内部有多级 Cache（L1/L2/L3）                    │
│    → Cache 使用 SRAM，速度极快                            │
│    → CPU ← L1 Cache ← L2 Cache ← L3 Cache ← 内存(DRAM)  │
└─────────────────────────────────────────────────────────┘
```

## 五、ROM（只读存储器）

### 5.1 ROM 基本概念

```
全称：Read Only Memory（只读存储器）

名称由来：
  → 早期这类存储器真的只能读、不能写
  → 数据出厂时就固化在芯片中
  → 用户无法修改

核心特点：
  → 非易失性（掉电数据不丢失）
  → 适合存储需要长期保存的数据
```

### 5.2 ROM 的发展路线

```
发展顺序（按时间线）：

Mask ROM（掩膜 ROM）
  ↓ 工厂一次性写入，不可修改
  ↓
PROM（可编程 ROM）
  ↓ 用户可一次性编程写入
  ↓
EPROM（可擦除可编程 ROM）
  ↓ 紫外线照射整片擦除，可重复编程
  ↓
EEPROM（电可擦除可编程 ROM）
  ↓ 电信号擦除，方便快捷
  ↓
Flash（闪存）
  → 在 EEPROM 基础上发展
  → 容量更大、速度更快、成本更低
  → 当前最主流的 ROM
```

## 六、各代 ROM 详解

### 6.1 Mask ROM（掩膜 ROM）

```
全称：Mask Read Only Memory

原理：
  → 使用特殊掩膜工艺生产
  → 出厂时数据直接通过掩膜方式写入并固化
  → 不可修改

特点：
  → 只能读，完全不能写
  → 数据永久固化
  → 适合大批量生产 → 成本低

应用：
  → 存放固定的程序（永远不变的程序）
  → 存放固定的数据（永远不变的数据）
  → 例：早期游戏卡带、计算器内置程序
```

### 6.2 PROM（可编程 ROM）

```
全称：Programmable Read Only Memory

背景：
  → 程序员对 Mask ROM 不满
  → "只让我读，不能改，太不方便了"
  → 需求：给我一个空白芯片，让我自己写入数据

原理（熔丝方式）：
  → 每一位由一根熔丝（fuse）连接
  → 熔丝连通 → 表示 1
  → 加电流烧断熔丝 → 表示 0（不可逆）

特点：
  → 用户可自行编程写入一次
  → 只能写一次（"一锤子买卖"）
  → 烧断后无法恢复

与 Mask ROM 对比：
  Mask ROM：工厂写死，用户不可改
  PROM：空白芯片，用户自己写一次
```

### 6.3 EPROM（可擦除可编程 ROM）

```
全称：Erasable Programmable Read Only Memory

原理：
  → 在 PROM 基础上增加擦除功能
  → 可通过紫外线照射整片擦除所有数据
  → 经典操作：紫外线照射约 30 分钟
  → 擦除后可重新编程写入

特点：
  → 可重复擦写（比 PROM 进步）
  → 但擦除方式麻烦（需要专用紫外线设备）
  → 只能整片擦除（无法按字节擦除）
  → 芯片上有石英窗口（用于紫外线照射）

识别方法：
  → 芯片上有一个小圆窗/小方窗
  → 看到石英窗口 → 就是 EPROM

从 EPROM 开始：
  → ROM 已经不再是"只读"了
  → 用特殊手段可以改变数据
  → "ROM"这个名称开始不太准确了
```

### 6.4 EEPROM（电可擦除可编程 ROM）

```
全称：Electrically Erasable Programmable Read Only Memory

关键进步：
  → 擦除手段从"紫外线照射"变为"电信号控制"
  → 不需要专用紫外线设备
  → 通过电路控制即可擦写
  → 极大提升了使用便利性

特点：
  → 电可擦除，方便快捷
  → 可按字节擦写（灵活度高）
  → 擦写速度相对较慢
  → 容量较小

典型芯片：
  → AT24C02（256 字节，I²C 接口）
  → 适合存储少量配置数据

ROM 的本质变化：
  → 从 EEPROM 开始，ROM 真正进入可读可写时代
  → "只读存储器"这个名称已经名不副实
```

### 6.5 Flash（闪存）

```
原理：
  → 底层原理与 EEPROM 相同（电可擦除）
  → 在 EEPROM 技术基础上进一步发展

相比 EEPROM 的优势：
  → 容量更大（可达数 MB 甚至数 GB）
  → 读取速度更快
  → 成本更低
  → 擦写方式优化（按块/扇区擦除，而非按字节）

特点：
  → 读取快，写入相对慢（需要先擦除再写入）
  → 非易失性（掉电数据不丢失）
  → 有擦写寿命（上万次到十万次）

当前应用：
  → 当前最主流的 ROM 类型
  → U 盘的存储介质 → Flash
  → 固态硬盘（SSD）的存储介质 → Flash
  → 手机存储芯片 → Flash（NAND Flash）
  → STM32 内部程序存储器 → Flash
  → W25Q32 外部存储芯片 → NOR Flash

Flash 的分类：
  ├── NOR Flash
  │   → 可按字节读取
  │   → 适合存储代码（可直接执行）
  │   → 例：W25Q32
  │
  └── NAND Flash
      → 按页/块读写
      → 容量更大、成本更低
      → 适合存储大量数据
      → 例：U 盘、SSD、手机存储
```

## 七、ROM 发展总结表

| 类型 | 全称 | 写入方式 | 擦除方式 | 可重复擦写 | 典型芯片 |
|------|------|---------|---------|:----------:|---------|
| **Mask ROM** | 掩膜 ROM | 工厂掩膜固化 | 不可擦除 | ❌ | 早期游戏卡带 |
| **PROM** | 可编程 ROM | 用户一次性编程 | 不可擦除 | ❌ | 熔丝式存储器 |
| **EPROM** | 可擦除可编程 ROM | 用户编程 | **紫外线**照射整片擦除 | ✅（整片） | 带石英窗芯片 |
| **EEPROM** | 电可擦除可编程 ROM | 用户编程 | **电信号**按字节擦除 | ✅（按字节） | AT24C02 |
| **Flash** | 闪存 | 用户编程 | **电信号**按块/扇区擦除 | ✅（按块） | W25Q32、SSD |

## 八、Flash 还能叫 ROM 吗？

### 8.1 名称的历史遗留问题

```
问题：
  → Flash 明显可以读也可以写
  → 为什么还叫 ROM（只读存储器）？

答案：历史名称的保留

类比生活中的例子：

① 汽车
   → 早期：烧汽油 → 叫"汽车"
   → 现在：很多是电动汽车
   → 但依然叫"汽车"（或简称"电车"做对比）

② 火车
   → 早期：蒸汽机车，烧煤冒火 → 叫"火车"
   → 现在：电气化高速列车/动车/高铁
   → 但依然叫"火车"（"坐火车回家"）

③ ROM
   → 早期：真的只能读不能写
   → 现在：Flash 可读可写
   → 但依然叫"ROM"

结论：
  → 技术名词经过发展变化后
  → 名称可能已不反映原始含义
  → 但原始名称会保留下来
```

### 8.2 ROM 与 RAM 的本质区别

```
虽然 ROM 现在也能读写了，但 ROM ≠ RAM，本质区别依然存在：

① 写入方式不同
   RAM → 直接改写（触发器翻转 / 电容充放电）→ 读写速度一样快
   Flash → 需要先擦除再写入 → 读取快，写入慢

② 擦写寿命不同
   RAM → 理论上无限读写（只要上电）
   Flash → 有擦写寿命上限（通常 1 万 ~ 10 万次）

③ 易失性不同
   RAM → 掉电数据丢失
   ROM（Flash）→ 掉电数据保持

④ 底层存储原理不同
   RAM → 电子电路状态（触发器 / 电容）
   Flash → 浮栅晶体管（电荷捕获）

⑤ 应用场景不同
   RAM → 运行时数据（变量、栈、堆）→ 需要频繁快速读写
   Flash → 长期存储（程序代码、固件、数据）→ 写入不频繁
```

## 九、STM32 中的 RAM 与 ROM

```
STM32F103C8T6 片内存储器：

┌──────────────────────────────────┐
│  Flash（ROM）— 64 KB             │
│  → 存储程序代码                   │
│  → 存储常量数据                   │
│  → 非易失性（掉电不丢失）          │
├──────────────────────────────────┤
│  SRAM（RAM）— 20 KB              │
│  → 存储运行时变量                 │
│  → 存储栈和堆                    │
│  → 易失性（掉电丢失）             │
│  → 直接使用 SRAM（无需 DRAM）     │
└──────────────────────────────────┘

对比个人电脑：
┌──────────────────────────────────┐
│  硬盘 / SSD（ROM）— 数百 GB ~ 数 TB│
│  → 存储操作系统、程序、文件        │
│  → 非易失性                      │
├──────────────────────────────────┤
│  内存（DRAM）— 数 GB ~ 数十 GB    │
│  → 运行程序时的数据               │
│  → 易失性                       │
├──────────────────────────────────┤
│  Cache（SRAM）— 数 MB            │
│  → CPU 高速缓存                  │
│  → 易失性，速度极快               │
└──────────────────────────────────┘

关键区别：
  → STM32：RAM 直接用 SRAM（容量小，20KB 够用，速度快）
  → PC：RAM 用 DRAM（容量大，需要数 GB）+ SRAM 做缓存
```

## 十、设计取舍的核心思想

```
贯穿所有存储器设计的核心规律：

┌─────────────────────────────────────────────────────┐
│                                                     │
│   追求速度 → 结构复杂 → 成本高 → 集成度低 → 容量小   │
│   例：SRAM → 用于 Cache                              │
│                                                     │
│   追求容量 → 结构简单 → 成本低 → 集成度高 → 速度慢   │
│   例：DRAM → 用于内存                                │
│                                                     │
│   追求持久 → 非易失 → 写入慢 → 有寿命限制             │
│   例：Flash → 用于长期存储                           │
│                                                     │
└─────────────────────────────────────────────────────┘

实际工程设计中：
  → 没有完美的器件，只有合适的器件
  → 根据应用场景选择最合适的存储器类型
  → 多种存储器配合使用，扬长避短
```

## 十一、关键概念速查

| 概念 | 说明 |
|------|------|
| RAM | 随机存取存储器，易失性，可读可写，随机访问 |
| SRAM | 静态 RAM，6T 触发器，不需要刷新，快但贵，用于 Cache |
| DRAM | 动态 RAM，1T1C 电容，需要定期刷新，慢但便宜，用于内存 |
| ROM | 只读存储器（历史名称），非易失性 |
| Mask ROM | 掩膜 ROM，工厂一次性写入，不可修改 |
| PROM | 可编程 ROM，用户一次性写入（熔丝方式） |
| EPROM | 可擦除可编程 ROM，紫外线照射整片擦除 |
| EEPROM | 电可擦除可编程 ROM，电信号按字节擦除 |
| Flash | 闪存，EEPROM 基础上发展，按块擦除，当前主流 ROM |
| 非易失性 | 掉电数据不丢失（ROM 的特征） |
| 易失性 | 掉电数据丢失（RAM 的特征） |
| 双稳态触发器 | SRAM 存储单元，6 个晶体管，断电才改变状态 |
| 电容充放电 | DRAM 存储原理，有电 = 1，无电 = 0 |
| 刷新操作 | DRAM 定期检查电容电量，> 1/2 判 1 并充满，< 1/2 判 0 并放电 |
| 浮栅晶体管 | Flash 存储原理，通过电荷捕获存储数据 |
| 擦写寿命 | Flash 擦写次数有限（1 万 ~ 10 万次），RAM 理论无限 |
| NOR Flash | 按字节读取，可执行代码，如 W25Q32 |
| NAND Flash | 按页/块读写，容量大成本低，如 U 盘、SSD |

## 十二、常见问题

| 问题 | 解答 |
|------|------|
| RAM 和 ROM 最大区别是什么？ | **易失性**：RAM 掉电丢数据，ROM 掉电不丢 |
| SRAM 和 DRAM 最大区别是什么？ | SRAM **不需要刷新**，DRAM **需要定期刷新** |
| 为什么 SRAM 比 DRAM 贵？ | SRAM 每位需 6 个晶体管，DRAM 只需 1 个晶体管 + 1 个电容 |
| DRAM 为什么需要刷新？ | 电容会自然放电/吸收电荷，必须定期刷新维持数据 |
| Flash 还算 ROM 吗？ | 技术上已可读可写，但名称历史保留，仍称为 ROM |
| Flash 和 RAM 能互相替代吗？ | 不能。Flash 写入慢、有寿命；RAM 掉电丢数据 |
| STM32 为什么直接用 SRAM 做内存？ | 容量小（20KB），SRAM 够用且速度快，无需 DRAM |
| EPROM 怎么识别？ | 芯片上有**石英窗口**（小圆窗/方窗）→ 就是 EPROM |
| EEPROM 和 Flash 区别？ | EEPROM 按**字节**擦写，Flash 按**块/扇区**擦除 |
| PROM 能写几次？ | 只能写**一次**（熔丝烧断不可恢复） |
| Cache 用什么做的？ | **SRAM**（速度快，容量小） |
| 电脑内存用什么做的？ | **DRAM**（容量大，成本低） |
| U 盘 / SSD 底层是什么？ | **Flash**（NAND Flash 为主） |
