# 第六章 FSMC 控制器 — 外部设备地址映射 笔记

---

## 一、FSMC 地址空间总览

### 1.1 FSMC 管理的地址范围

```
FSMC 管理的地址空间位于存储器映射的 Block 3 和 Block 4：

  Block 3：0x6000_0000 ~ 0x7FFF_FFFF（512 MB）
  Block 4：0x8000_0000 ~ 0x9FFF_FFFF（512 MB）

  FSMC 总共可管理的地址空间 = 512 MB + 512 MB = 1 GB
```

### 1.2 四个 Bank 的划分

```
1 GB 地址空间划分为 4 个 Bank（区），每个 Bank 256 MB：

  Bank     地址范围                   大小      支持的存储器类型
  ─────────────────────────────────────────────────────────────
  Bank 1   0x6000_0000 ~ 0x6FFF_FFFF  256 MB    NOR Flash / PSRAM / SRAM
  Bank 2   0x7000_0000 ~ 0x7FFF_FFFF  256 MB    NAND Flash
  Bank 3   0x8000_0000 ~ 0x8FFF_FFFF  256 MB    NAND Flash
  Bank 4   0x9000_0000 ~ 0x9FFF_FFFF  256 MB    PC Card

  → 不同类型的外部存储器映射到不同的 Bank
  → 每个 Bank 可通过配置寄存器进行独立配置
```

---

## 二、Bank 大小计算

### 2.1 每个 Bank 的大小验证

```
Bank 1 地址范围：0x6000_0000 ~ 0x6FFF_FFFF

大小 = 0x7000_0000 - 0x6000_0000 = 0x1000_0000

  0x1000_0000 = 16^7 = (2^4)^7 = 2^28

  2^28 = 2^8 × 2^20 = 256 × 1M = 256 MB ✅

总空间验证：
  4 个 Bank × 256 MB = 1024 MB = 1 GB = 2^30 ✅
```

---

## 三、Bank 1 详解 — NOR Flash / PSRAM / SRAM

### 3.1 Bank 1 的子分区

```
Bank 1（256 MB）进一步划分为 4 个子区，每个 64 MB：

  子区        片选信号   地址范围                   大小
  ──────────────────────────────────────────────────────
  Bank1-1     NE1       0x6000_0000 ~ 0x63FF_FFFF   64 MB
  Bank1-2     NE2       0x6400_0000 ~ 0x67FF_FFFF   64 MB
  Bank1-3     NE3       0x6800_0000 ~ 0x6BFF_FFFF   64 MB
  Bank1-4     NE4       0x6C00_0000 ~ 0x6FFF_FFFF   64 MB

  → 每个子区对应一个独立的片选信号（NE1 ~ NE4）
  → 最多可同时连接 4 片 NOR Flash / PSRAM / SRAM 芯片
  → 每片芯片占用一个子区的地址空间
```

### 3.2 子区大小计算

```
每个子区大小 = 256 MB ÷ 4 = 64 MB

验证（以 Bank1-1 为例）：
  地址范围：0x6000_0000 ~ 0x63FF_FFFF

  大小 = 0x6400_0000 - 0x6000_0000 = 0x0400_0000

  0x0400_0000 = 4 × 16^6 = 2^2 × (2^4)^6 = 2^2 × 2^24 = 2^26

  2^26 = 2^6 × 2^20 = 64 × 1M = 64 MB ✅
```

## 四、Bank 2 & Bank 3 — NAND Flash

### 4.1 地址分配

```
Bank 2（NAND Flash 1）：
  地址范围：0x7000_0000 ~ 0x7FFF_FFFF
  大小：256 MB
  存储器类型：NAND Flash

Bank 3（NAND Flash 2）：
  地址范围：0x8000_0000 ~ 0x8FFF_FFFF
  大小：256 MB
  存储器类型：NAND Flash
```

### 4.2 NAND Flash 容量特点

```
NAND Flash 与 NOR Flash 的容量对比：

  NOR Flash：容量相对较小（几 MB ~ 几十 MB）
  NAND Flash：容量很大（几百 MB ~ 几 GB）

  原因：
    → NAND Flash 使用与非门作为底层存储单元
    → 集成度更高，单位面积存储密度更大
    → 因此每个 Bank 256 MB 的地址空间对 NAND Flash 来说很合理

  应用：
    → NAND Flash 适合大容量数据存储
    → 类似于固态硬盘（SSD）的底层存储介质
```

## 七、Bank 配置寄存器

```
每个 Bank 都有独立的配置寄存器，可单独进行配置：

  → 存储器类型选择（NOR Flash / SRAM / NAND Flash ...）
  → 数据宽度选择（8 位 / 16 位）
  → 读写时序参数配置
  → 等待信号使能
  → 片选信号配置

配置寄存器地址：位于 Block 5（0xA000_0000 起）

  → FSMC 的配置寄存器单独放在 Block 5
  → 不与外设寄存器混在 Block 2 中
  → 因为 FSMC 模块比较特殊，功能独立
```

## 八、地址映射的实际意义

### 8.1 CPU 访问外部存储器的过程

```
CPU 访问外部 SRAM 的完整路径：

  ① CPU 发出地址，如 0x6800_0010
  ② 地址通过 AHB 总线传递
  ③ FSMC 检测到地址落在 Bank 1-3 范围内（0x6800_0000 ~ 0x6BFF_FFFF）
  ④ FSMC 拉低 NE3 片选信号 → 选中连接在 NE3 上的 SRAM 芯片
  ⑤ FSMC 通过地址线 A[25:0] 发出偏移地址 0x0010
  ⑥ FSMC 通过数据线 D[15:0] 进行数据读写
  ⑦ 外部 SRAM 芯片响应读写操作

效果：
  → CPU 只需要给出一个地址
  → FSMC 自动完成片选、地址发送、读写控制
  → CPU 感觉就像在访问片内内存一样简单
```

### 8.2 多片存储器的地址分配

```
示例：连接两片 SRAM 芯片

  SRAM 芯片 A → 连接 NE1 → 地址范围 0x6000_0000 ~ 0x63FF_FFFF（64 MB）
  SRAM 芯片 B → 连接 NE3 → 地址范围 0x6800_0000 ~ 0x6BFF_FFFF（64 MB）

  CPU 访问 0x6000_0000 → FSMC 自动选中芯片 A
  CPU 访问 0x6800_0000 → FSMC 自动选中芯片 B

  → 不需要手动控制片选
  → FSMC 根据地址自动判断选中哪片芯片
```

## 九、关键概念速查

| 概念 | 说明 |
|------|------|
| FSMC 地址空间 | Block 3 + Block 4 = 1 GB（0x6000_0000 ~ 0x9FFF_FFFF） |
| Bank | FSMC 将 1 GB 空间分为 4 个区，每个 256 MB |
| Bank 1 | NOR Flash / PSRAM / SRAM，256 MB，分为 4 个子区 |
| Bank 2 | NAND Flash 1，256 MB |
| Bank 3 | NAND Flash 2，256 MB |
| Bank 4 | PC Card，256 MB |
| Bank1-1 ~ Bank1-4 | Bank 1 的 4 个子区，每个 64 MB，对应 NE1 ~ NE4 |
| NE1 ~ NE4 | Bank 1 的 4 个片选信号，低电平有效 |
| 256 MB 计算 | 0x1000_0000 = 2^28 = 256 × 2^20 = 256 MB |
| 64 MB 计算 | 0x0400_0000 = 2^26 = 64 × 2^20 = 64 MB |
| NAND Flash 容量大 | 因为与非门存储单元集成度高，每个 Bank 256 MB |
| 配置寄存器 | 每个 Bank 有独立的配置寄存器，位于 Block 5 |

## 十、常见问题

| 问题 | 解答 |
|------|------|
| FSMC 管理多大地址空间？ | **1 GB**（Block 3 + Block 4） |
| 每个 Bank 多大？ | **256 MB**（1 GB ÷ 4） |
| Bank 1 能接几片芯片？ | **4 片**（4 个子区，NE1 ~ NE4） |
| 每个子区多大？ | **64 MB**（256 MB ÷ 4） |
| SRAM 映射到哪个 Bank？ | **Bank 1**（0x6000_0000 起） |
| NAND Flash 映射到哪？ | **Bank 2**（0x7000_0000）和 **Bank 3**（0x8000_0000） |
| 实际 SRAM 芯片只有几 MB，为什么分配了 64 MB？ | 地址空间是预分配的，实际使用只占一小部分，剩余地址空闲 |
| FSMC 根据什么选中芯片？ | 根据 CPU 给出的**地址范围**自动判断选中对应的 NE 片选 |
| 配置寄存器在哪个地址？ | **Block 5**（0xA000_0000 起），FSMC 寄存器独立存放 |
| Bank 4 一般用来做什么？ | PC Card，一般不使用 |
