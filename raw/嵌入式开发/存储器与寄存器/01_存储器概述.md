## 二、存储器的本质与作用

### 2.1 什么是存储器

```
定义：
  存储器是用于存储信息的计算机部件
  是现代计算机结构中非常重要的组成部分

冯·诺依曼体系结构的本质：
  → 存储程序和数据
  → 执行程序，进行控制
  → 存储器 = 存储代码和数据的核心部件

存储器中存放的信息：
  → 本质是一串 0 和 1 的二进制序列
  → 可以是要执行的代码/指令
  → 也可以是具体要用到的数据
```

### 2.2 存储器的重要性

```
① 记住数据
   → 计算机可以将需要的数据保存下来
   → 后续需要时可以随时读取使用

② 记住程序
   → 计算机知道自己接下来要执行什么任务
   → 按照存储的指令顺序逐条执行

没有存储器 → 计算机无法记住任何东西 → 无法工作
```

## 三、存储器的分类总览

### 3.1 按存储特性划分：RAM 与 ROM

```
存储器
├── RAM（Random Access Memory，随机存取存储器）
│   ├── SRAM（Static RAM，静态 RAM）
│   └── DRAM（Dynamic RAM，动态 RAM）
│
├── ROM（Read Only Memory，只读存储器）
│   ├── Mask ROM（掩膜 ROM）
│   ├── PROM（Programmable ROM，可编程 ROM）
│   ├── EPROM（Erasable PROM，可擦除可编程 ROM）
│   ├── EEPROM（Electrically Erasable PROM，电可擦除可编程 ROM）
│   └── Flash（闪存）← 当前主流
│
└── 其他类型（存储介质不同）
    ├── 机械硬盘（HDD）
    ├── 软盘
    ├── 磁带
    └── 光盘（CD / DVD / BD）
```

### 3.2 RAM 与 ROM 的核心区别

| 对比项 | RAM | ROM |
|--------|-----|-----|
| 原始定义 | 可读可写存储器 | 只读存储器（只能读不能写） |
| **核心区别（易失性）** | **易失性**存储器 | **非易失性**存储器 |
| 掉电表现 | **掉电数据丢失** | **掉电数据不丢失** |
| 别称 | — | 持久化存储器 |
| 典型应用 | 运行时变量、数据缓存 | 程序代码、固件、配置数据 |

```
为什么现在用"易失性"而非"可读写"来区分？

早期：
  → ROM 确实只能读不能写
  → RAM 可读可写
  → 这是二者最大的区别

现在：
  → 随着技术发展，ROM 也变得可读可写了（如 EEPROM、Flash）
  → 单从"可读写"角度已无法区分
  → 因此现在以"易失性"（掉电是否丢数据）作为核心区分依据
```

## 四、RAM 详解

### 4.1 SRAM（静态 RAM）

```
特点：
  → 不需要刷新，数据保持稳定
  → 速度快
  → 成本高
  → 集成度低（同样面积存储容量小）
  → 体积大

典型应用：
  → CPU 内部缓存（Cache / L1 / L2 / L3）
  → 对速度要求极高的场景

结构特点：
  → 每个存储单元需要多个晶体管（通常 6 个）
  → 因此集成度低、成本高
```

### 4.2 DRAM（动态 RAM）

```
特点：
  → 需要定期刷新（否则数据会丢失）
  → 速度相对 SRAM 较慢
  → 成本较低
  → 集成度高（同样面积存储容量大）

典型应用：
  → 电脑内存条（DDR SDRAM）
  → STM32 内部的 RAM
  → 大容量主存

结构特点：
  → 每个存储单元只需要 1 个晶体管 + 1 个电容
  → 电容会漏电 → 需要周期性刷新
  → 因此集成度高、成本低
```

### 4.3 SRAM 与 DRAM 对比

| 对比项 | SRAM | DRAM |
|--------|------|------|
| 刷新 | 不需要 | 需要定期刷新 |
| 速度 | 快 | 较慢 |
| 成本 | 高 | 低 |
| 集成度 | 低 | 高 |
| 典型用途 | CPU Cache | 内存条、片内 RAM |

## 五、ROM 的发展与 Flash

### 5.1 ROM 的技术发展路线

```
发展顺序（按时间线）：

Mask ROM（掩膜 ROM）
  ↓ 工厂生产时一次性写入，不可修改
PROM（可编程 ROM）
  ↓ 用户可一次性编程（熔丝方式）
EPROM（可擦除可编程 ROM）
  ↓ 紫外线照射擦除，可重复编程
  ↓ 芯片上有石英窗口（看到芯片上的小圆窗就是它）
EEPROM（电可擦除可编程 ROM）
  ↓ 电信号擦除，无需紫外线，按字节擦写
  ↓ 例：AT24C02
Flash（闪存）
  → 在 EEPROM 技术基础上发展而来
  → 按块/扇区擦除，按字节/页写入
  → 速度快、容量大、成本低
  → 当前最主流的 ROM 类型
  → 例：W25Q32（NOR Flash）、STM32 内部 Flash
```

### 5.2 Flash（闪存）

```
本质：
  → 是一种 ROM（非易失性存储器）
  → 在 EEPROM 技术基础上发展而来的新型存储技术
  → 掉电不丢失数据

特点：
  → 按块擦除（EEPROM 按字节擦除）
  → 擦写速度更快
  → 存储密度更高
  → 成本更低

当前应用：
  → 电脑中的 ROM 基本都是 Flash
  → STM32 内部的程序存储器 = Flash
  → U 盘、SSD 固态硬盘的存储介质也是 Flash
  → 手机存储芯片也是 Flash（NAND Flash）
```

## 六、按存储介质划分

### 6.1 三大存储介质类型

```
存储器按存储介质划分：

① 半导体存储器
   → 存储介质：半导体元器件（电子器件）
   → 通过电信号存储 0 和 1
   → 包括：SRAM、DRAM、Flash、EEPROM 等
   → 特点：速度快、体积小、功耗相对低

② 磁介质存储器
   → 存储介质：磁性材料
   → 通过磁化方向存储 0 和 1
   → 包括：机械硬盘（HDD）、软盘、磁带
   → 特点：容量大、成本低、速度慢

③ 光介质存储器
   → 存储介质：光磁介质
   → 通过激光读写
   → 包括：CD、DVD、蓝光光盘（BD）
   → 特点：稳定性好、容量大、便携
```

### 6.2 分类对比

| 介质类型 | 存储方式 | 代表设备 | 速度 | 成本 | 趋势 |
|---------|---------|---------|------|------|------|
| 半导体 | 电信号 | Flash、RAM | 快 | 较高 | **主流方向** |
| 磁介质 | 磁信号 | 机械硬盘、磁带 | 慢 | 低 | 逐步淘汰 |
| 光介质 | 光信号 | CD/DVD/BD | 中 | 低 | 仍有部分场景 |

## 七、磁介质存储器详解

### 7.1 机械硬盘（HDD）

```
工作原理：
  → 内部有一个或多个圆形磁盘（盘片）
  → 磁盘高速旋转（如 7200 RPM）
  → 磁头在半径方向来回移动（寻道）
  → 通过物理方式定位到某个磁性存储单元
  → 这种物理寻址方式 → 速度很慢

优点：
  ✅ 单位存储容量价格便宜（唯一的优点）

缺点：
  ❌ 体积大
  ❌ 速度慢（机械寻址 vs 电子寻址）
  ❌ 怕摔怕震动（机械结构，磁头容易损坏盘片）
  ❌ 有噪音（盘片旋转 + 磁头移动）
  ❌ 功耗较高

与固态硬盘（SSD）对比：
  → SSD 基于 Flash 芯片，纯电子化
  → HDD 相比 SSD → 几乎全是缺点
  → 唯一优势：便宜
  → 但 Flash 芯片价格持续下降 → HDD 正逐步被淘汰
```

### 7.2 软盘（Floppy Disk）

```
什么是软盘：
  → 小型、薄片状的软性磁盘
  → 使用磁性介质存储数据
  → 早期电脑的主要外部存储设备

经典规格：
  → 3.5 英寸软盘
  → 容量：约 1.44 MB（经典款）
  → 大容量款也只有几 MB

现状：
  → 已基本完全淘汰
  → 但留下了历史印记：
    → Word 软件的"保存"图标 💾 就是软盘的形状
    → 因为早期存盘操作就是存到软盘上

思考：
  → 为什么被淘汰？
  → 现在一个普通文件都远超 1.44 MB
  → 容量太小，完全无法满足现代需求
```

### 7.3 磁带（Magnetic Tape）

```
特点：
  → 磁性介质
  → 成本非常低
  → 可以大容量存储
  → 顺序访问（非随机访问）→ 查找速度慢

历史应用：
  → 早期听歌买磁带（比 CD 便宜）
  → 早期数据备份的主要介质

现状：
  → 消费级市场基本淘汰
  → 企业级数据备份仍有使用（成本优势）
```

### 7.4 光盘（Optical Disc）

```
类型：
  → CD（容量约 700 MB）
  → DVD（单层约 4.7 GB）
  → 蓝光 BD（单层约 25 GB）

特点：
  → 光磁介质，稳定性好
  → 容量相对较大
  → 成本低
  → 便携

现状：
  → 仍有部分使用场景
  → 但已不如从前普及
```

## 八、STM32 中的存储器

### 8.1 片内存储器

```
STM32 内部包含两片存储器：

① Flash（闪存）
   → 类型：ROM（非易失性）
   → 用途：存储程序代码、常量数据
   → 掉电不丢失
   → 例：STM32F103C8T6 → 64 KB Flash

② RAM（随机存取存储器）
   → 类型：SRAM（易失性）
   → 用途：存储运行时的变量、栈、堆
   → 掉电数据丢失
   → 例：STM32F103C8T6 → 20 KB SRAM
```

### 8.2 片外扩展存储器

```
通过通信协议扩展外部存储设备：

① EEPROM（I²C 协议）
   → AT24C02 → 256 字节
   → 非易失性，按字节擦写
   → 适合存储小量配置数据

② NOR Flash（SPI 协议）
   → W25Q32 → 4 MB
   → 非易失性，按扇区擦除
   → 适合存储大量数据或代码
```

## 九、存储器知识体系总结

```
                        ┌─ SRAM（快、贵、小）→ CPU Cache
            ┌─ RAM ─────┤
            │  (易失性)  └─ DRAM（慢、便宜、大）→ 内存条、片内 RAM
            │
存储器 ─────┤            ┌─ Mask ROM / PROM / EPROM
            │  ┌─ ROM ───┤
            ├─┤  (非易失) ├─ EEPROM（AT24C02）
            │  │         └─ Flash（W25Q32、SSD、U盘、STM32 Flash）
            │  │
            │  ├─ 磁介质 ─── 机械硬盘 / 软盘 / 磁带
            └──┤
               └─ 光介质 ─── CD / DVD / BD

寄存器：
  → 也具有存储功能
  → 存在于每个外设模块内部
  → 与存储器的关系 → 后续章节详细讲解
```

## 十、关键概念速查

| 概念 | 说明 |
|------|------|
| RAM | 随机存取存储器，易失性，掉电丢数据 |
| ROM | 只读存储器（现在基本都可读写），非易失性 |
| SRAM | 静态 RAM，速度快、成本高，用于 CPU Cache |
| DRAM | 动态 RAM，需刷新、成本低，用于内存 |
| Flash | 闪存，当前主流 ROM，基于 EEPROM 技术发展 |
| EEPROM | 电可擦除可编程 ROM，按字节擦写，如 AT24C02 |
| 易失性 | 掉电数据丢失（RAM 的特征） |
| 非易失性 | 掉电数据不丢失（ROM 的特征） |
| 半导体存储器 | 以电子元器件为存储介质（RAM/ROM/Flash） |
| 磁介质存储器 | 以磁性材料为存储介质（硬盘/软盘/磁带） |
| 光介质存储器 | 以光磁材料为存储介质（CD/DVD/BD） |
| 寄存器 | 具有存储功能的部件，存在于外设模块内部（后续详解） |
| 冯·诺依曼体系 | 存储程序和数据 → 执行程序 → 控制 |
| 机械硬盘 | 磁存储、机械寻址、便宜但慢，正逐步被淘汰 |
| 软盘 | 1.44 MB 容量，已淘汰，Word 保存图标来源 |

## 十一、常见问题

| 问题 | 解答 |
|------|------|
| RAM 和 ROM 最大的区别是什么？ | **易失性**：RAM 掉电丢数据，ROM 掉电不丢 |
| Flash 属于 RAM 还是 ROM？ | 属于 **ROM**（非易失性存储器） |
| STM32 内部有哪些存储器？ | **Flash**（程序存储）+ **SRAM**（运行时数据） |
| EEPROM 和 Flash 的区别？ | EEPROM 按**字节**擦写，Flash 按**块/扇区**擦除 |
| 为什么机械硬盘正在被淘汰？ | 速度慢、怕摔、有噪音，Flash 价格持续下降 |
| 软盘图标为什么还在 Word 里？ | 历史遗留，早期存盘操作就是存到软盘 |
| 寄存器是存储器吗？ | 具有存储功能，但本质不同于存储器（后续详解） |
| 为什么 SRAM 比 DRAM 贵？ | SRAM 每单元需 6 个晶体管，DRAM 只需 1 个晶体管 + 1 个电容 |
