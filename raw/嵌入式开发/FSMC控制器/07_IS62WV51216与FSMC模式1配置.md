# IS62WV51216 + FSMC 模式 1 配置详解

## 一、IS62WV51216 关键时序参数（查手册）

IS62WV51216 有两种常见速度等级：

| 参数 | 符号 | -55 等级 | -45 等级 | 说明 |
|------|------|---------|---------|------|
| 读周期时间 | tRC | 55 ns | 45 ns | 最小读周期 |
| 地址访问时间 | tAA | 55 ns | 45 ns | 地址有效 → 数据有效 |
| OE 到数据有效 | tDOE | 25 ns | 20 ns | NOE↓ → 数据输出 |
| 写周期时间 | tWC | 55 ns | 45 ns | 最小写周期 |
| WE 脉冲宽度 | tPWE | 40 ns | 35 ns | NWE 低电平最小宽度 |
| 地址建立到写结束 | tAW | 45 ns | 40 ns | 地址有效 → NWE↑ |
| 数据建立到写结束 | tSD | 25 ns | 20 ns | 数据有效 → NWE↑ |
| 地址建立时间 | tSA | 0 ns | 0 ns | 地址在 NWE↓ 前建立 |
| 地址保持时间 | tHA | 0 ns | 0 ns | 地址在 NWE↑ 后保持 |

## 二、FSMC 模式 1 时序结构

FSMC 模式 1（SRAM/PSRAM）的读写时序分为两个关键阶段：

```
读操作时序：
                  ┌── ADDSET ──┐┌────── DATAST ──────┐
  HCLK  ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
          └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘

  ADDR   ════════════════════════════════════════════════
         地址有效                                      地址保持

  NEx    ───┐                                 ┌──────────
            └─────────────────────────────────┘

  NOE    ─────────┐                     ┌────────────────
                   └─────────────────────┘
                   │←── DATAST+1 周期 ──→│
                   ↑                     ↑
                   数据采样窗口          数据在此锁存
```

```
写操作时序：
                  ┌── ADDSET ──┐┌────── DATAST ──────┐
  HCLK  ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐
          └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘

  ADDR   ════════════════════════════════════════════════
         地址有效                ↑写结束    地址保持

  NWE    ─────────┐                     ┌────────────────
                   └─────────────────────┘
                   │←── DATAST+1 周期 ──→│
                   ↑ NWE↓                ↑ NWE↑ (数据锁存)
```

> **核心关系（STM32F1 RM0008）：**
> - **地址建立时间** = (ADDSET) × t_HCLK（ADDSET阶段持续 ADDSET+1 个HCLK周期）
> - **数据阶段时间**：
>   - 读操作 = (DATAST + 3) × t_HCLK  ← RM0008 定义读DATAST为DATAST+3
>   - 写操作 = (DATAST + 1) × t_HCLK  ← NOE/NWE 有效持续时间
> - **总读周期** = (ADDSET + 1) + (DATAST + 3) = (ADDSET + DATAST + 4) × t_HCLK
> - **总写周期** = (ADDSET + 1) + (DATAST + 1) = (ADDSET + DATAST + 2) × t_HCLK

## 三、约束不等式推导

以 IS62WV51216LL**-55** 为例，建立以下不等式组：

### 读操作

| # | 约束来源 | 不等式 | 说明 |
|---|---------|--------|------|
| R1 | tRC | (ADDSET + DATAST + 4) × t_HCLK ≥ **55 ns** | 最小读周期 |
| R2 | tAA | (ADDSET + DATAST) × t_HCLK ≥ **55 ns** | 地址到数据有效（注1） |
| R3 | tDOE | (DATAST + 3) × t_HCLK ≥ **25 ns** | NOE 低电平时间 |

> 注1：tAA约束基于AN2784应用笔记，考虑ADDSET期间地址已开始译码
> R1和R2共同决定ADDSET下限，R3约束DATAST的下限。

### 写操作

| # | 约束来源 | 不等式 | 说明 |
|---|---------|--------|------|
| W1 | tWC | (ADDSET + DATAST + 2) × t_HCLK ≥ **55 ns** | 最小写周期 |
| W2 | tPWE | (DATAST + 1) × t_HCLK ≥ **40 ns** | **写脉冲宽度，约束最严** |
| W3 | tAW | (ADDSET + DATAST + 2) × t_HCLK ≥ **45 ns** | 地址建立到写结束 |
| W4 | tSD | (DATAST + 1) × t_HCLK ≥ **25 ns** | 数据建立到写结束 |
| W5 | tSA | ADDSET × t_HCLK ≥ **0 ns** | 地址建立（天然满足） |

## 四、不同 HCLK 频率下的计算

### 以 HCLK = 72 MHz 为例（t_HCLK = 13.89 ns）

**步骤 1：确定 DATAST 下限**

```
读约束 R3:  (DATAST + 3) ≥ 25 / 13.89 = 1.80  → DATAST ≥ -1.2（无实际约束）
写约束 W2:  (DATAST + 1) ≥ 40 / 13.89 = 2.88  → DATAST ≥ 2  ← 最严
写约束 W4:  (DATAST + 1) ≥ 25 / 13.89 = 1.80  → DATAST ≥ 1

∴ DATAST ≥ 2
```

**步骤 2：确定 ADDSET 下限**

```
读约束 R1:  ADDSET + DATAST + 4 ≥ 55 / 13.89 = 3.96 → ADDSET + DATAST ≥ 0（无实际约束）
读约束 R2:  ADDSET + DATAST ≥ 55 / 13.89 = 3.96 → ADDSET + DATAST ≥ 4
写约束 W1:  ADDSET + DATAST + 2 ≥ 55 / 13.89 = 3.96 → ADDSET + DATAST ≥ 2

当 DATAST = 2 时: ADDSET ≥ 4 - 2 = 2（由读约束R2决定）
```

**步骤 3：验证**

```
ADDSET = 2, DATAST = 2

读: (2+2+4) × 13.89 = 111.12 ns ≥ 55 ns (tRC)  ✓✓ （裕量充足）
读: (2+2) × 13.89 = 55.56 ns ≥ 55 ns (tAA)  ✓  （余量 0.56ns，偏紧）
读: (2+3) × 13.89 = 69.45 ns ≥ 25 ns (tDOE) ✓✓
写: (2+1) × 13.89 = 41.67 ns ≥ 40 ns (tPWE) ✓  （余量 1.67ns）
写: (2+2+2) × 13.89 = 83.34 ns ≥ 55 ns (tWC)  ✓✓
```

**步骤 4：建议增加裕量**

```
推荐: ADDSET = 2, DATAST = 2  （满足所有约束，有足够裕量）

读: (2+2+4) × 13.89 = 111.1 ns ≥ 55 ns (tRC)  ✓✓ （裕量 56.1 ns）
读: (2+2) × 13.89 = 55.6 ns ≥ 55 ns (tAA)  ✓✓ （裕量 0.6 ns）
读: (2+3) × 13.89 = 69.4 ns ≥ 25 ns (tDOE) ✓✓ （裕量 44.4 ns）
写: (2+1) × 13.89 = 41.7 ns ≥ 40 ns (tPWE) ✓  （裕量 1.7 ns）
写: (2+2+2) × 13.89 = 83.3 ns ≥ 55 ns (tWC)  ✓✓ （裕量 28.3 ns）
```

## 五、完整代码（STM32F103 @ 72MHz）

```c
#include "stm32f10x.h"

void FSMC_SRAM_Init(void)
{
    GPIO_InitTypeDef         GPIO_InitStruct;
    FSMC_NORSRAMInitTypeDef  FSMC_InitStruct;
    FSMC_NORSRAMTimingInitTypeDef  readTiming, writeTiming;

    /* ========== 1. 开启时钟 ========== */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOD |
                           RCC_APB2Periph_GPIOE |
                           RCC_APB2Periph_GPIOF |
                           RCC_APB2Periph_GPIOG, ENABLE);
    RCC_AHBPeriphClockCmd(RCC_AHBPeriph_FSMC, ENABLE);

    /* ========== 2. 配置 GPIO（16 位数据总线） ========== */
    // PD0,1: D2,D3  PD4: NOE  PD5: NWE  PD7: NCE/CS
    // PD8~15: D13~D8 (D8~D15)
    // PE0,1: NBL0,NBL1  PE7~15: D4~D12
    // PF0~5: A0~A5  PF12~15: A6~A9
    // PG0~5: A10~A15  PG9: A16~A23 (bank select)

    // ... GPIO 初始化代码（省略，使用默认推挽复用输出） ...

    /* ========== 3. FSMC 读时序配置 ========== */
    // 计算过程:
    //   HCLK = 72MHz, tHCLK = 13.89ns
    //   读约束: ADDSET + DATAST + 4 >= ceil(55/13.89) = 4 → ADDSET + DATAST >= 0
    //           ADDSET + DATAST >= ceil(55/13.89) = 4（tAA约束）
    //           DATAST + 3 >= ceil(25/13.89) = 2 → DATAST >= -1（无约束）
    //   写约束: ADDSET + DATAST + 2 >= ceil(55/13.89) = 4 → ADDSET + DATAST >= 2
    //           DATAST + 1 >= ceil(40/13.89) = 3 → DATAST >= 2
    //   推荐: ADDSET=2, DATAST=2 → 读总周期=111.1ns, 写总周期=83.3ns

    readTiming.FSMC_AddressSetupTime      = 2;   // ADDSET = 2
    readTiming.FSMC_AddressHoldTime       = 0;   // ADDHLD (模式1最小值0)
    readTiming.FSMC_DataSetupTime         = 2;   // DATAST = 2 → (2+1)×13.89 = 41.67ns
    readTiming.FSMC_BusTurnAroundDuration = 0;   // 总线周转
    readTiming.FSMC_CLKDivision           = 0;   // 不分频
    readTiming.FSMC_DataLatency           = 0;   // 异步模式无效
    readTiming.FSMC_AccessMode            = FSMC_AccessMode_A;

    /* ========== 4. FSMC 写时序配置 ========== */
    // 写约束: ADDSET + DATAST + 2 >= ceil(55/13.89) = 4 → ADDSET + DATAST >= 2
    //         DATAST + 1 >= ceil(40/13.89) = 3 → DATAST >= 2
    // 推荐: ADDSET=2, DATAST=2 → 与读时序相同

    writeTiming.FSMC_AddressSetupTime      = 2;  // ADDSET = 2
    writeTiming.FSMC_AddressHoldTime       = 0;
    writeTiming.FSMC_DataSetupTime         = 2;  // DATAST = 2 → (2+1)×13.89 = 41.67ns
    writeTiming.FSMC_BusTurnAroundDuration = 0;
    writeTiming.FSMC_CLKDivision           = 0;
    writeTiming.FSMC_DataLatency           = 0;
    writeTiming.FSMC_AccessMode            = FSMC_AccessMode_A;

    /* ========== 5. FSMC Bank 配置 ========== */
    FSMC_InitStruct.FSMC_Bank                  = FSMC_Bank1_NORSRAM1;
    FSMC_InitStruct.FSMC_DataAddressMux        = FSMC_DataAddressMux_Disable;
    FSMC_InitStruct.FSMC_MemoryType            = FSMC_MemoryType_SRAM;
    FSMC_InitStruct.FSMC_MemoryDataWidth       = FSMC_MemoryDataWidth_16b;
    FSMC_InitStruct.FSMC_BurstAccessMode       = FSMC_BurstAccessMode_Disable;
    FSMC_InitStruct.FSMC_WaitSignalPolarity    = FSMC_WaitSignalPolarity_Low;
    FSMC_InitStruct.FSMC_WrapMode              = FSMC_WrapMode_Disable;
    FSMC_InitStruct.FSMC_WaitSignalActive      = FSMC_WaitSignalActive_BeforeWaitState;
    FSMC_InitStruct.FSMC_WriteOperation        = FSMC_WriteOperation_Enable;
    FSMC_InitStruct.FSMC_WaitSignal            = FSMC_WaitSignal_Disable;
    FSMC_InitStruct.FSMC_ExtendedMode          = FSMC_ExtendedMode_Enable;  // 读写独立时序
    FSMC_InitStruct.FSMC_WriteBurst            = FSMC_WriteBurst_Disable;
    FSMC_InitStruct.FSMC_ReadWriteTimingStruct = &readTiming;
    FSMC_InitStruct.FSMC_WriteTimingStruct     = &writeTiming;

    FSMC_NORSRAMInit(&FSMC_InitStruct);
    FSMC_NORSRAMCmd(FSMC_Bank1_NORSRAM1, ENABLE);
}

/* 测试读写 */
void SRAM_Test(void)
{
    // Bank1_NORSRAM1 基地址: 0x60000000
    volatile uint16_t *sram = (volatile uint16_t *)0x60000000;

    sram[0] = 0x1234;       // 写
    sram[1] = 0xABCD;

    uint16_t d0 = sram[0];  // 读 → 应返回 0x1234
    uint16_t d1 = sram[1];  // 读 → 应返回 0xABCD
}
```

## 六、计算公式速查卡

```
┌─────────────────────────────────────────────────────────┐
│  FSMC 模式 1 — 通用计算公式（基于RM0008）               │
│                                                         │
│  已知: 芯片时序参数 (tRC, tAA, tDOE, tWC, tPWE, tSD)   │
│        HCLK 频率 → t_HCLK = 1 / HCLK                   │
│                                                         │
│  ① DATAST = max(                                        │
│        ⌈tPWE / t_HCLK⌉ - 1,    // 写: NWE 脉冲宽度     │
│        ⌈tSD  / t_HCLK⌉ - 1     // 写: 数据建立时间     │
│     )                                                    │
│     注: 读DOE约束为 DATAST+3 ≥ tDOE/t_HCLK，通常自动满足│
│                                                         │
│  ② ADDSET = max(                                        │
│        ⌈tAA / t_HCLK⌉ - DATAST,   // 读: 地址访问时间  │
│        ⌈tRC / t_HCLK⌉ - 4 - DATAST, // 读: 总读周期    │
│        ⌈tWC / t_HCLK⌉ - 2 - DATAST, // 写: 总写周期    │
│        0                                                │
│     )                                                    │
│                                                         │
│  ③ 验证:                                                │
│     读: (ADDSET + DATAST + 4) × t_HCLK ≥ max(tRC)      │
│     读: (ADDSET + DATAST) × t_HCLK ≥ tAA               │
│     写: (ADDSET + DATAST + 2) × t_HCLK ≥ max(tWC)      │
│     写: (DATAST + 1) × t_HCLK ≥ max(tPWE, tSD)         │
│                                                         │
│  ④ 建议: ADDSET 或 DATAST 加 1~2 作为裕量               │
└─────────────────────────────────────────────────────────┘
```
