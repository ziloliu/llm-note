# 第六章 FSMC 控制器 — IS62WV51216 SRAM 芯片详解 笔记

---

## 一、存储器扩展目标

### 1.1 为什么扩展 SRAM

```
STM32 片内 SRAM 仅 64 KB：
  → 大量数据处理场景不够用
  → 图像处理、大数组、复杂算法等需要更多内存

扩展方案：
  → 使用 FSMC 连接外部 SRAM 芯片
  → 扩展运行内存（RAM），而非程序存储（ROM）
  → CPU 通过 FSMC 像访问片内内存一样访问外部 SRAM

为什么扩展 SRAM 而非 Flash：
  → SRAM 是真正的运行内存
  → 可随机读写，无需擦除
  → 读写速度快
  → 适合频繁读写的运行时数据
```

## 二、IS62WV51216 芯片概述

### 2.1 命名解析

```
芯片名称：IS62WV51216

  512 → 512K 个存储单元（524288 个）
  16  → 每个存储单元 16 位（2 字节）

容量计算：
  512K 个单元 × 2 字节/单元 = 1024 KB = 1 MB

  → 扩展后 CPU 可访问 1 MB 的外部 SRAM 空间
```

### 2.2 基本参数

| 参数 | 值 |
|------|-----|
| 芯片型号 | IS62WV51216 |
| 存储类型 | SRAM（静态随机存取存储器） |
| 存储单元数 | 512K（524288 个） |
| 每单元位宽 | 16 位（2 字节） |
| 总容量 | **1 MB** |
| 数据宽度 | 16 位 |
| 地址线 | 19 根（A0 ~ A18） |
| 数据线 | 16 根（IO0 ~ IO15） |

## 三、IS62WV51216 引脚定义

### 3.1 引脚总览

```
┌────────────────────────────────────────────────────────────┐
│                    IS62WV51216 引脚分类                      │
├────────────────────────────────────────────────────────────┤
│  地址引脚（输入）                                           │
│    A0 ~ A18（共 19 根）                                    │
│    → 19 位地址可寻址 2^19 = 512K 个存储单元                 │
├────────────────────────────────────────────────────────────┤
│  数据引脚（输入/输出）                                      │
│    IO0 ~ IO7   → 低 8 位（低位字节）                       │
│    IO8 ~ IO15  → 高 8 位（高位字节）                       │
│    → 共 16 根，双向传输                                    │
├────────────────────────────────────────────────────────────┤
│  控制引脚（输入）                                           │
│    CS   → 片选信号（低电平有效）                            │
│    OE   → 输出使能 / 读使能（低电平有效）                   │
│    WE   → 写使能（低电平有效）                              │
│    UB   → 高字节使能（低电平有效）                          │
│    LB   → 低字节使能（低电平有效）                          │
├────────────────────────────────────────────────────────────┤
│  电源引脚                                                   │
│    VDD → 电源（3.3V）                                     │
│    GND → 地                                                │
└────────────────────────────────────────────────────────────┘
```

### 3.2 各引脚功能详解

```
① 地址引脚 A0 ~ A18（共 19 根）
   → 类型：输入（I）
   → 功能：接收地址信号，选择 512K 个存储单元中的一个
   → 19 根线 → 2^19 = 512K 个不同地址 → 与存储单元数吻合
   → 连接 FSMC 的地址线

② 数据引脚 IO0 ~ IO15（共 16 根）
   → 类型：输入/输出（I/O）
   → 功能：传输 16 位数据
   → IO0 ~ IO7：低 8 位（低位字节）
   → IO8 ~ IO15：高 8 位（高位字节）
   → 连接 FSMC 的数据线 D[15:0]

③ 片选信号 CS（低电平有效）
   → 类型：输入
   → CS1 低电平有效，CS2 高电平有效（部分型号有两个）
   → 一般只使用一个即可
   → CS = 0 → 芯片被选中，可以进行读写
   → CS = 1 → 芯片未选中，数据线高阻态
   → 连接 FSMC 的 NE 片选信号

④ 读使能信号 OE（低电平有效）
   → 类型：输入
   → 全称：Output Enable（输出使能）
   → 对于存储器而言，输出 = 主机读取它
   → OE = 0 → SRAM 将数据输出到数据总线（读操作）
   → 连接 FSMC 的 NOE 信号

⑤ 写使能信号 WE（低电平有效）
   → 类型：输入
   → 全称：Write Enable（写使能）
   → WE = 0 → SRAM 从数据总线接收数据（写操作）
   → 连接 FSMC 的 NWE 信号

⑥ 高字节使能 UB（低电平有效）
   → 类型：输入（手册标为 O，实际为输入控制）
   → 全称：Upper Byte enable
   → UB = 0 → 高 8 位（IO8 ~ IO15）有效
   → UB = 1 → 高 8 位被屏蔽

⑦ 低字节使能 LB（低电平有效）
   → 类型：输入（手册标为 O，实际为输入控制）
   → 全称：Lower Byte enable
   → LB = 0 → 低 8 位（IO0 ~ IO7）有效
   → LB = 1 → 低 8 位被屏蔽
   → UB/LB 连接 FSMC 的 NBL 信号
```

### 3.3 信号类型总结

```
引脚        类型      说明
────────────────────────────────────
A0 ~ A18    I        地址输入
IO0 ~ IO15  I/O      数据输入/输出
CS          I        片选（低有效）
OE          I        读使能（低有效）
WE          I        写使能（低有效）
UB          I        高字节使能（低有效）
LB          I        低字节使能（低有效）
VDD         —        电源 3.3V
GND         —        地
```

### 4.2 工作流程

```
① 地址译码
   → 19 根地址线输入地址信号
   → 地址译码器（Decoder）选中 512K 个存储单元中的一个

② 控制逻辑
   → CS = 0：芯片被选中
   → OE = 0：数据从存储阵列输出到 IO 引脚（读）
   → WE = 0：数据从 IO 引脚写入存储阵列（写）
   → UB/LB：控制高/低字节的使能

③ 数据通路
   → 存储单元 = 16 位
   → 一次读写 = 16 位（2 字节）
   → UB/LB 可单独屏蔽高/低字节
```

## 五、不同数据宽度的操作方式

### 5.1 16 位操作（标准）

```
写入 16 位数据：
  → UB = 0, LB = 0（16 位全部有效）
  → 地址线输出目标地址
  → 数据线 D[15:0] 输出 16 位数据
  → 一次写入 2 字节

读取 16 位数据：
  → UB = 0, LB = 0
  → 地址线输出目标地址
  → 数据线 D[15:0] 读取 16 位数据
```

### 5.2 8 位操作（单字节）

```
读/写低字节：
  → UB = 1, LB = 0（只使能低 8 位）
  → 数据线 D[7:0] 有效，D[15:8] 被屏蔽

读/写高字节：
  → UB = 0, LB = 1（只使能高 8 位）
  → 数据线 D[15:8] 有效，D[7:0] 被屏蔽
```

### 5.3 32 位操作（双字）

```
32 位数据需要分两次 16 位操作：

写入 32 位数据（如 uint32_t data = 0x12345678）：

  第一次写（低 16 位）：
    地址 = base_addr
    数据 = 0x5678（低 16 位）
    → 写入 2 字节

  第二次写（高 16 位）：
    地址 = base_addr + 2（地址加 2，因为每个单元 2 字节）
    数据 = 0x1234（高 16 位）
    → 写入 2 字节

  → 两次操作合并 = 完整的 32 位数据
  → 连续地址存放，地址递增 2

读取 32 位数据：
  → 第一次读：地址 base_addr → 得到低 16 位
  → 第二次读：地址 base_addr + 2 → 得到高 16 位
  → 合并：data = (高 16 位 << 16) | 低 16 位
```

## 六、FSMC 与 IS62WV51216 连接

### 6.1 信号线连接表

```
FSMC 信号          IS62WV51216 引脚    功能
──────────────────────────────────────────────────────
A[18:0]      ←→    A0 ~ A18           19 根地址线
D[15:0]      ←→    IO0 ~ IO15         16 根数据线
NE           ──→    CS                 片选信号（低有效）
NOE          ──→    OE                 读使能（低有效）
NWE          ──→    WE                 写使能（低有效）
NBL1         ──→    UB                 高字节使能（低有效）
NBL0         ──→    LB                 低字节使能（低有效）
HCLK         ──→    （内部同步，不外接） 时钟信号
VDD          ──→    VDD                3.3V 电源
GND          ──→    GND                地
```

### 6.2 存储器映射

```
连接到 Bank 1 的某个子区（假设使用 NE3）：

  SRAM 地址范围：0x6800_0000 ~ 0x680F_FFFF

  大小：
    2^19 个单元 × 2 字节 = 1 MB = 0x10_0000

  CPU 访问方式：
    → 读 16 位：直接访问某个地址
    → 读 8 位：配合 UB/LB 选择高/低字节
    → 读 32 位：连续访问两个 16 位地址，合并结果

  FSMC 配置要点：
    → BCR 寄存器：MWID = 16 位（数据宽度）
    → BCR 寄存器：MTYP = SRAM（存储器类型）
    → 使用模式 1（最简单）
    → BTR 寄存器：配置 AddSet 和 DataSet
```

## 八、FSMC 时序参数配置

### 8.1 配置目标

```
使用模式 1 配置 FSMC，需要设置的关键参数：

   ① AddSet（地址建立时间）：ADDSET 阶段 = AddSet + 1 个 HCLK 周期
   ② DataSet（数据建立时间）：DATAST 阶段 = DataSet + 3（读）或 DataSet + 1（写）个 HCLK 周期

HCLK = 72 MHz → 单个时钟周期 ≈ 1/72 MHz ≈ 13.9 ns
```

### 8.2 AddSet 配置

```
地址建立时间要求：

   读操作：tAA = 55 ns（地址到数据有效的延迟）
   写操作：tSA ≥ 0 ns（下限为 0，地址可与WE同时变化）

约束条件：
   → 写操作：AddSet × t_HCLK ≥ tSA(0 ns) → 无实际约束
   → 读操作：总读周期 (AddSet+DataSet+4) × t_HCLK ≥ tRC(55 ns)
   → 当 DataSet 已确定时，由总周期约束反推 AddSet 最小值
```

### 8.3 DataSet 配置

```
数据建立时间要求：

   写操作：tPWE ≥ 40 ns（WE 有效宽度）
   读操作：tDOE ≥ 25 ns（OE 到数据有效时间）

模式 1 中：
   → 写操作 WE 有效宽度 = (DataSet + 1) × t_HCLK
   → 读操作 NOE 有效时间 = (DataSet + 3) × t_HCLK（RM0008 定义）
   → 需要满足：(DataSet + 1) × 13.9 ns ≥ 40 ns（写约束，最严格）

计算：
   DataSet + 1 ≥ 40 / 13.9 ≈ 2.88
   DataSet ≥ 1.88
   → 取整：DataSet ≥ 2

推荐配置值：

   配置值    实际写脉宽时间          是否满足
   ──────────────────────────────────────
     0       1 × 13.9 = 13.9 ns    ❌ 不够
     1       2 × 13.9 = 27.8 ns    ❌ 不够
     2       3 × 13.9 = 41.7 ns    ✅ 满足（刚好）
     3       4 × 13.9 = 55.6 ns    ✅ 满足（有余量）
     5       6 × 13.9 = 83.4 ns    ✅ 满足（余量充足）
```

### 8.4 最终配置方案

```c
/* FSMC 时序配置（模式 1） */

/* 方案一：最紧凑配置 */
AddSet = 1;    /* 地址建立 = 2 个周期 */
DataSet = 2;   /* 数据建立 = 3 个周期（写）= 41.7 ns ≥ 40 ns ✅ */
/* 读总周期 = (1+2+4) × 13.9 = 97.3 ns ≥ 55 ns ✅ */
/* 写总周期 = (1+2+2) × 13.9 = 69.5 ns ≥ 55 ns ✅ */

/* 方案二：有裕量（推荐） */
AddSet = 2;    /* 地址建立 = 3 个周期 */
DataSet = 2;   /* 数据建立 = 3 个周期（写）= 41.7 ns ≥ 40 ns ✅ */
/* 读总周期 = (2+2+4) × 13.9 = 111.2 ns ≥ 55 ns ✅ */
/* 写总周期 = (2+2+2) × 13.9 = 83.4 ns ≥ 55 ns ✅ */
```

### 8.5 配置速查表

| 参数 | 芯片要求 | 配置值 | 实际时间 | 满足？ |
|------|---------|:------:|---------|:------:|
| AddSet | 由总周期约束决定 | 2 | 3 × 13.9 = 41.7 ns | ✅ |
| DataSet（写） | tPWE ≥ 40 ns | 2 | (2+1) × 13.9 = 41.7 ns | ✅ |
| 总读周期 | tRC ≥ 55 ns | AddSet=2,DataSet=2 | (2+2+4) × 13.9 = 111.2 ns | ✅ |
| 总写周期 | tWC ≥ 55 ns | AddSet=2,DataSet=2 | (2+2+2) × 13.9 = 83.4 ns | ✅ |

## 九、时序参数对应关系

### 9.1 芯片参数 ↔ FSMC 配置

```
IS62WV51216 参数    FSMC 配置参数    对应关系
──────────────────────────────────────────────────
tSA（地址建立时间）  AddSet          AddSet × t_HCLK ≥ tSA(0 ns)
tPWE（WE 有效宽度）  DataSet         (DataSet+1) × t_HCLK ≥ tPWE(40 ns)
tAA（地址访问时间）  AddSet+DataSet   (AddSet+DataSet) × t_HCLK ≥ tAA(55 ns)（见注）
tDOE（OE访问时间）   DataSet         (DataSet+3) × t_HCLK ≥ tDOE(25 ns)
tRC（读周期时间）    总读时间         (AddSet+DataSet+4) × t_HCLK ≥ tRC(55 ns)
tWC（写周期时间）    总写时间         (AddSet+DataSet+2) × t_HCLK ≥ tWC(55 ns)

注：RM0008 定义 DATAST 阶段读操作为 DATAST+3 个 HCLK 周期，写操作为 DATAST+1 个 HCLK 周期
读操作总时间 = (AddSet + 1) + (DataSet + 3) = AddSet + DataSet + 4 个 HCLK 周期
写操作总时间 = (AddSet + 1) + (DataSet + 1) = AddSet + DataSet + 2 个 HCLK 周期
```

### 9.2 模式 1 读时序关键点

```
模式 1 读时序简化说明：

   ① 地址建立阶段（ADDSET）：
      → 地址线输出有效地址
      → 片选拉低
      → NOE 也拉低（读使能有效）
      → 持续 AddSet + 1 个周期

   ② 数据建立阶段（DATAST）：
      → 等待外部 SRAM 输出数据
      → NOE 保持低电平
      → 持续 DataSet + 3 个周期（读操作）
      → 数据在此阶段内被采样

   ③ 数据保持阶段：
      → NOE 拉高后数据保持至少 1 个周期
```

### 9.3 模式 1 写时序关键点

```
模式 1 写时序简化说明：

   ① 地址建立阶段（ADDSET）：
      → 地址线输出有效地址
      → 片选拉低
      → 持续 AddSet + 1 个周期

   ② 写入阶段（DATAST）：
      → NWE 拉低（写使能有效）
      → FSMC 将数据驱动到数据总线
      → 持续 DataSet + 1 个周期（写操作）
      → 外部 SRAM 在此期间锁存数据

   ③ 数据保持阶段：
      → NWE 恢复高电平后
      → 数据在总线上继续保持至少 1 个周期
```

## 十一、常见问题

| 问题                 | 解答                               |
| ------------------ | -------------------------------- |
| IS62WV51216 总容量多大？ | **1 MB**（512K 单元 × 2 字节/单元）      |
| 地址线多少根？            | **19 根**（A0~A18）                 |
| 数据线多少根？            | **16 根**（IO0~IO15）               |
| 怎么读一个字节？           | 用 **UB/LB** 屏蔽，只取需要的 8 位         |
| 怎么读 32 位数据？        | 分**两次** 16 位读取，地址递增 2，合并结果       |
| 读周期时间多少？           | 典型 **55 ns**                     |
| 写周期时间多少？           | 典型 **55 ns**                     |
| WE 有效宽度至少多少？       | 至少 **40 ns**（tPWE）               |
| 地址建立时间有下限吗？        | **没有**，可配最小值                     |
| DataSet 至少配多少？     | **≥ 2**（(2+1) × 13.9 = 41.7 ns ≥ 40 ns tPWE） |
| AddSet 至少配多少？      | **≥ 2**（72MHz推荐值，由总周期约束决定） |
| CS 有几个？            | CS1（低有效）和 CS2（高有效），一般**只用一个**    |
| 为什么不用 SDRAM？       | FSMC **只支持静态存储器**，SDRAM 是动态的     |
