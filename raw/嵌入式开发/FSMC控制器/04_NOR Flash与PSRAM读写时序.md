# 第六章 FSMC 控制器 — NOR Flash / PSRAM 读写时序 笔记

---

## 一、FSMC 时序控制的意义

### 1.1 为什么需要时序控制

```
FSMC 的核心任务：
  → 将 AHB 总线上的读写控制信号、数据、地址
  → 转换为外部存储器可识别的通信协议时序

什么是时序？
  → 时间序列
  → 所有信号（地址、数据、控制）按时间顺序排列
  → 什么时候传地址、什么时候传数据、什么时候控制信号有效
  → 这些都必须严格按时间顺序执行

本质：
  → 时序控制 = 保证通信协议的正确执行
  → FSMC 内部集成协议转换模块
  → 自动完成时序控制，用户只需配置参数
```

### 1.2 时钟同步

```
时钟来源：
  → HCLK（AHB 高速系统总线时钟）
  → FSMC 内部所有信号由 HCLK 保持同步

时钟是否输出到外部？
  → 正常情况下不输出
  → 靠内部时序控制来保证通信协议的稳定性
  → 外部存储器不需要接收时钟信号
  → 只需要按照控制信号的时序响应即可

同步写模式（特殊）：
  → 仅 PSRAM 可开启
  → 开启后会有存储器时钟输出到外部
  → SRAM / ROM 不支持此模式
```

### 1.3 关键时序要求

```
① 片选信号 NE 必须在失效前完成数据采样
   → 片选失效后无法通信
   → 必须在 NE 有效期间完成数据读写

② 所有控制器输出信号在内部时钟（HCLK）上升沿变化
   → 信号变化与 HCLK 同步

③ 同步写模式下（仅 PSRAM）
   → 读写数据在存储器时钟下降沿变化
```

## 二、FSMC 的六种工作模式

### 2.1 模式总览

```
FSMC 控制 NOR Flash / PSRAM 支持六种模式：

  模式        名称              特点
  ──────────────────────────────────────────────────────
  模式 1      Mode 1            最简单，读写合一配置
  模式 A      Mode A            扩展模式，读写分离配置
  模式 B      Mode B (2B)       扩展模式
  模式 C      Mode C            扩展模式
  模式 D      Mode D            扩展模式
  复用模式    Multiplexed       地址线和数据线复用
```

### 2.2 模式 1 vs 扩展模式

```
模式 1（最简单）：
  → 只用一个时序寄存器（BTR）控制读写时序
  → 读时序和写时序共用同一套配置
  → NOE 始终保持低电平有效（比扩展模式更简单）

扩展模式（模式 A / B / C / D）：
  → 读时序和写时序可分别独立配置
  → 用 BTR 配置读时序
  → 用 BWTR 配置写时序
  → 灵活性更高，可针对读写分别优化时序参数
```

### 2.3 复用模式

```
地址数据复用模式：
  → 地址线和数据线共用同一组引脚
  → 先传地址，再传数据（分时复用）
  → 目的：减少引脚数量，提升集成度
  → 协议更复杂，需要额外的时序控制
  → 需要 NADV（地址有效）信号区分地址和数据阶段
```

### 3.1 读时序图

![[Pasted image 20260911110940.png]]
### 3.2 读时序各阶段详解

```
阶段一：地址建立（Address Setup）

  时间：AddSet + 1 个 HCLK 周期
  操作：
    → FSMC 在地址线 A[25:0] 上输出目标地址
    → 片选信号 NE 拉低（有效）
    → 数据掩码 NBL 设定（选择高/低字节）
    → 读使能 NOE 保持高电平（暂不读取）
    → 写使能 NWE 保持高电平
  目的：
    → 给外部存储器足够的时间接收和解码地址
    → 地址建立完成后，外部存储器知道要访问哪个存储单元

阶段二：数据建立（Data Setup）

  时间：DataSet + 1 个 HCLK 周期
  操作：
    → 读使能 NOE 拉低（有效）→ 使能外部存储器输出数据
    → 外部存储器根据地址将数据输出到 D[15:0] 数据总线
    → 数据总线由外部存储器驱动
    → FSMC 等待数据稳定
  目的：
    → 等待外部存储器把数据放到数据总线上
    → 数据信号需要一定时间才能稳定

阶段三：数据读取

  时间：在数据建立期间完成
  操作：
    → FSMC 在合适的时刻采样数据总线 D[15:0]
    → 将 16 位数据读入内部

阶段四：数据保持（Data Hold）

  时间：至少 2 个 HCLK 周期
  操作：
    → 数据在总线上继续保持有效
    → 读使能 NOE 关闭（恢复高电平）前数据必须保持
    → 不能读完数据就立刻释放数据总线
  目的：
    → 保证数据采样的可靠性
    → 防止数据信号被过早释放导致采样错误

阶段五：读使能关闭

  操作：
    → NOE 恢复高电平（无效）
    → 数据总线释放
    → NE 可恢复高电平（无效）
```

### 3.3 读时序信号变化顺序

```
时间轴 →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→

① NE 拉低（片选有效）
② 地址线输出有效地址
③ NBL 设定字节选择
④ 等待 AddSet + 1 个周期（地址建立）
⑤ NOE 拉低（读使能有效）
⑥ 等待外部存储器输出数据到数据总线
⑦ 等待 DataSet + 1 个周期（数据建立）
⑧ 采样数据总线，读取数据
⑨ 数据保持至少 2 个周期
⑩ NOE 恢复高电平（读使能无效）
⑪ NE 恢复高电平（片选无效）
```

## 四、模式 A 写时序详解

### 4.1 写时序图
![[Pasted image 20260911111633.png]]
### 4.2 写时序各阶段详解

```
阶段一：地址建立（Address Setup）

  时间：AddSet + 1 个 HCLK 周期
  操作：
    → FSMC 在地址线 A[25:0] 上输出目标地址
    → 片选信号 NE 拉低（有效）
    → 数据掩码 NBL 设定
    → 写使能 NWE 保持高电平（暂不写入）
    → 读使能 NOE 保持高电平
  目的：
    → 给外部存储器时间接收和解码地址

阶段二：写入数据（Data Setup）

  时间：DataSet + 1 个 HCLK 周期
  操作：
    → 写使能 NWE 拉低（有效）
    → FSMC 同时将数据输出到数据总线 D[15:0]
    → 数据总线由 FSMC 驱动（主设备主动发送数据）
    → 外部存储器接收地址和数据
  关键点：
    → NWE 拉低和数据输出几乎同时发生（同一时刻）
    → 数据由 FSMC（主设备）驱动到总线上
    → 外部存储器在 NWE 有效期间锁存数据

阶段三：数据保持（Data Hold）

  时间：NWE 关闭后至少保持 1 个 HCLK 周期
  操作：
    → NWE 恢复高电平（写使能无效）
    → 数据在总线上继续保持有效至少 1 个周期
    → 确保外部存储器完成数据锁存
  目的：
    → NWE 关闭后数据不能立即释放
    → 需要保持一段时间让外部存储器可靠锁存

阶段四：写使能关闭

  操作：
    → 数据保持时间结束后，释放数据总线
    → NE 恢复高电平（片选无效）
```

### 4.3 写时序信号变化顺序

```
时间轴 →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→

① NE 拉低（片选有效）
② 地址线输出有效地址
③ NBL 设定字节选择
④ 等待 AddSet + 1 个周期（地址建立）
⑤ NWE 拉低（写使能有效）
⑥ FSMC 将数据输出到数据总线
⑦ 等待 DataSet + 1 个周期（数据建立/写入）
⑧ NWE 恢复高电平（写使能无效）
⑨ 数据在总线上继续保持至少 1 个周期（数据保持）
⑩ 释放数据总线
⑪ NE 恢复高电平（片选无效）
```

## 五、读时序 vs 写时序对比

### 5.1 关键区别

| 对比项 | 读操作 | 写操作 |
|--------|--------|--------|
| 有效控制信号 | NOE（读使能） | NWE（写使能） |
| 无效控制信号 | NWE 保持高 | NOE 保持高 |
| 数据总线驱动方 | **外部存储器**驱动 | **FSMC（主设备）**驱动 |
| 数据方向 | 外部存储器 → FSMC | FSMC → 外部存储器 |
| 数据保持目的 | 保证采样可靠性 | 保证外部存储器锁存数据 |
| DataSet 含义 | 等待外部存储器输出数据 | FSMC 持续输出写入数据 |

### 5.2 信号状态对比

```
          读操作                    写操作
  ─────────────────────    ─────────────────────
  NE:    低（有效）          NE:    低（有效）
  NOE:   低（有效）          NOE:   高（无效）
  NWE:   高（无效）          NWE:   低（有效）
  地址:  FSMC 输出           地址:  FSMC 输出
  数据:  外部存储器输出       数据:  FSMC 输出
```

## 六、关键时序参数

### 6.1 参数定义

```
① AddSet（地址建立时间）
   → 寄存器中设置的值
   → 实际地址建立时间 = AddSet + 1 个 HCLK 周期
   → 作用：给外部存储器时间接收和解码地址
   → 取值范围：0 ~ 15（4 位）

② DataSet（数据建立时间）
   → 寄存器中设置的值
   → 实际数据建立时间 = DataSet + 1 个 HCLK 周期
   → 读操作：等待外部存储器输出数据
   → 写操作：FSMC 持续输出数据的时间
   → 取值范围：0 ~ 255（8 位）

③ 数据保持时间
   → 读操作：至少 1 个 HCLK 周期
   → 写操作：NWE 关闭后至少 1 个 HCLK 周期
   → 由硬件自动保证
```

### 6.2 时间计算

```
读操作总时间：
  = (AddSet + 1) + (DataSet + 1) + 数据保持时间
  = (AddSet + 1) + (DataSet + 1) + 1
  = AddSet + DataSet + 3 个 HCLK 周期

写操作总时间：
  = (AddSet + 1) + (DataSet + 1) + 数据保持时间
  = (AddSet + 1) + (DataSet + 1) + 1
  = AddSet + DataSet + 3 个 HCLK 周期

示例：
  HCLK = 72 MHz → 1 个周期 ≈ 13.9 ns
  AddSet = 1, DataSet = 1
  → 读/写总时间 = 1 + 1 + 3 = 5 个周期 ≈ 69.4 ns
```

## 八、数据掩码（NBL）信号

### 8.1 功能说明

```
NBL[1:0] = Byte Lane（字节选择信号）

  NBL0：低字节（Lower Byte）使能
  NBL1：高字节（Upper Byte）使能

16 位数据总线 D[15:0] 分为两部分：

  ┌────────┬────────┐
  │ D[15:8]│ D[7:0] │
  │ 高字节  │ 低字节  │
  └────────┴────────┘
     ↑         ↑
   NBL1      NBL0

使能组合：
  NBL1=0, NBL0=0 → 传输完整 16 位数据
  NBL1=1, NBL0=0 → 只传输低字节（D[7:0]）
  NBL1=0, NBL0=1 → 只传输高字节（D[15:8]）
```

### 8.2 掩码概念类比

```
NBL 的作用类似子网掩码：

  子网掩码：
    255.255.255.0 → 与 IP 地址做按位与 → 提取网络号

  NBL 掩码：
    → 与 16 位数据做按位与
    → 选择性地传输高字节或低字节
    → 本质上就是按位与操作

实际应用：
  → 写入 8 位数据时，通过 NBL 选择高/低字节
  → 读取 8 位数据时，通过 NBL 屏蔽不需要的字节
  → 实现不同数据宽度的灵活传输
```

## 九、时序参数的配置寄存器

### 9.1 寄存器概览

```
FSMC NOR Flash / PSRAM 配置寄存器：

  模式 1：
    → BCR（Bus Configuration Register）：基本控制配置
    → BTR（Bus Timing Register）：读写时序配置（合一）

  模式 A：
    → BCR：基本控制配置
    → BTR：读时序配置
    → BWTR（Bus Write Timing Register）：写时序配置

BCR 主要配置内容：
  → 存储器类型选择
  → 数据宽度选择（8 / 16 位）
  → 读写使能
  → 等待信号使能
  → 其他控制位

BTR / BWTR 主要配置内容：
  → AddSet（地址建立时间）
  → DataSet（数据建立时间）
  → 数据保持时间
  → 总线转换周期
  → 时钟分频（同步模式）
```

### 9.2 BTR 寄存器关键位域

```
BTR（读时序寄存器）关键位：

  位域          名称          功能
  ──────────────────────────────────────────
  [3:0]        ADDSET        地址建立时间 = ADDSET + 1 个 HCLK
  [7:4]        ADDHLD        地址保持时间（复用模式使用）
  [15:8]       DATASET       数据建立时间 = DATASET + 1 个 HCLK
  [19:16]      BUSTURN       总线转换周期
  [23:20]      CLKDIV        时钟分频系数（同步模式）
  [27:24]      DATLAT        数据延迟（同步模式）

BWTR（写时序寄存器）关键位：
  → 位域定义与 BTR 相同
  → 独立控制写操作的时序参数
```

## 十、不同模式的时序特征总结

```
模式 1（最简单）：
  → NOE 始终保持低电平
  → 读写合一（BTR 配置）
  → 适合大多数 SRAM / NOR Flash

模式 A（扩展，读写分离）：
  → NOE 地址建立后才拉低
  → 读写分离（BTR + BWTR）
  → 适合读写速度不同的存储器

模式 B：
  → 类似模式 A，时序细节略有不同
  → 也叫模式 2B

模式 C：
  → 进一步扩展模式
  → 更复杂的时序控制

模式 D：
  → 进一步扩展模式
  → 更复杂的时序控制

复用模式：
  → 地址线和数据线共用
  → 需要 NADV 信号区分地址/数据阶段
  → 引脚最少，协议最复杂
```

## 十一、关键概念速查

| 概念 | 说明 |
|------|------|
| 时序 | 信号按时间顺序排列的序列，保证通信协议正确执行 |
| HCLK | AHB 总线时钟，FSMC 时序的时间基准 |
| AddSet | 地址建立时间参数，实际 = AddSet + 1 个 HCLK 周期 |
| DataSet | 数据建立时间参数，实际 = DataSet + 1 个 HCLK 周期 |
| 数据保持 | 读写操作后数据需继续保持有效的时间（≥ 1 周期） |
| NOE | 读使能信号（Output Enable），低电平有效 |
| NWE | 写使能信号（Write Enable），低电平有效 |
| NE | 片选信号（Chip Enable），低电平有效 |
| NBL | 数据掩码/字节选择信号，控制高/低字节传输 |
| NADV | 地址有效信号，复用模式中区分地址和数据 |
| BCR | 总线配置寄存器，配置基本控制参数 |
| BTR | 总线时序寄存器，配置读时序参数 |
| BWTR | 总线写时序寄存器，配置写时序参数（扩展模式） |
| 模式 1 | 最简单模式，读写合一，NOE 始终有效 |
| 模式 A | 扩展模式，读写分离，NOE 延迟有效 |
| 读写分离 | 读时序和写时序可独立配置不同参数 |
| 地址数据复用 | 地址线和数据线共用，分时传递地址和数据 |

## 十二、常见问题

| 问题                  | 解答                                   |
| ------------------- | ------------------------------------ |
| AddSet 实际时间怎么算？     | **AddSet + 1** 个 HCLK 周期             |
| DataSet 实际时间怎么算？    | **DataSet + 1** 个 HCLK 周期            |
| 读操作数据总线谁驱动？         | **外部存储器**驱动                          |
| 写操作数据总线谁驱动？         | **FSMC（主设备）**驱动                      |
| 模式 1 和模式 A 的区别？     | 模式 1 读写合一（BTR），模式 A 读写分离（BTR + BWTR） |
| 为什么写操作数据要多保持 1 个周期？ | 确保外部存储器可靠**锁存**写入的数据                 |
| 为什么读操作数据要保持？        | 确保 FSMC 可靠**采样**读取的数据                |
| NBL 有什么用？           | 选择传输**高字节**或**低字节**，支持 8 位数据传输       |
| FSMC 时钟会输出到外部吗？     | 正常**不会**，靠内部时序控制；同步写模式（PSRAM）除外      |
| 哪种模式最简单？            | **模式 1**，NOE 始终有效，读写合一配置             |
| 什么场景用模式 A？          | 读写速度**不同**的存储器，需要分别配置时序参数            |
| 数据保持时间由谁保证？         | **硬件自动保证**，至少 1 个 HCLK 周期            |
