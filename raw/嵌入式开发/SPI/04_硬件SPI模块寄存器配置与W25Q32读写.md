# STM32 硬件 SPI 模块 — 寄存器配置与 W25Q32 读写 笔记

---

## 一、硬件 SPI 读写 W25Q32 的连接方式

### 1.1 连接方式不变

```
硬件 SPI 模块 vs 软件模拟：
  → 底层硬件连线完全相同！
  → CS  → PC13（GPIO，不连 PA4/NSS）
  → SCK → PA5（SPI1_SCK）
  → MOSI → PA7（SPI1_MOSI）
  → MISO → PA6（SPI1_MISO）

  开发板上硬件连线已固定，无法更改
```

### 1.2 PA4 (NSS) 引脚处理

```
PA4 是 STM32 SPI1 的 NSS 引脚：
  → 功能：让 STM32 被别人选为从设备（输入信号）
  → 现在 STM32 是主设备，不需要被选中
  → W25Q32 的 CS 连接的是 PC13，不连 PA4

两种处理方式：

方式一：硬件 NSS（需跳线）
  → 将 PA4 硬连线到 3.3V（高电平 = 不被选中 = 主设备）
  → 需要额外硬件操作

方式二：软件 NSS（推荐）
  → CR1.SSM = 1（软件从设备管理）
  → CR1.SSI = 1（内部从设备选择 = 主设备）
  → 无需额外硬件连线，纯寄存器配置即可
```

## 二、NSS 引脚扩展说明

### 2.1 NSS 的三种模式

| 模式 | 配置 | 连接 | 功能 |
|------|------|------|------|
| 硬件输入（从模式） | SSM=0 | PA4 接外部片选 | 被主设备选中 |
| 硬件输入拉高（主模式） | SSM=0 | PA4 接 3.3V | 永不被选中 |
| 软件管理（主模式） | SSM=1, SSI=1 | 无需连接 | 软件模拟高电平 |

### 2.2 NSS 输出模式（广播功能）

```
CR2.SSOE = 1（SS Output Enable）：
  → 主模式下，NSS 从输入变为输出
  → 从 PA4 引脚主动输出低电平
  → 如果连接到所有从设备的 CS 线 → 广播模式
  → 同时选中所有从设备，同时发送数据

使用场景：
  → 多个从设备需要同时接收相同数据
  → 例：多个 DAC 同步更新输出
```

## 三、SPI 寄存器总览

| 寄存器 | 名称 | 功能 |
|--------|------|------|
| **CR1** | 控制寄存器 1 | 主模式/波特率/极性/相位/使能等 |
| **CR2** | 控制寄存器 2 | 中断使能/DMA/SSOE 等 |
| **SR** | 状态寄存器 | TXE/RXNE/BSY 等标志位 |
| **DR** | 数据寄存器 | 写入=发送，读取=接收（16 位） |
| CRCPR | CRC 多项式 | CRC 校验配置（不用） |
| RXCRCR | 接收 CRC | 接收 CRC 值（不用） |
| TXCRCR | 发送 CRC | 发送 CRC 值（不用） |
| I2SCFGR | I2S 配置 | I2S 音频模式（不用） |
| I2SPR | I2S 预分频 | I2S 预分频（不用） |

```
实际需要关注的寄存器：
  ✅ CR1（主要配置）
  ✅ CR2（SSOE）
  ✅ SR（状态标志）
  ✅ DR（数据读写）

不需要关注的寄存器：
  ❌ CRC 相关（CRCPR/RXCRCR/TXCRCR）
  ❌ I2S 相关（I2SCFGR/I2SPR）
```

## 四、CR1 控制寄存器 1 详解

### 4.1 CR1 位域定义

| 位 | 名称 | 功能 | 配置值 |
|:--:|------|------|:------:|
| 0 | **CPHA** | 时钟相位 | **0**（Mode 0） |
| 1 | **CPOL** | 时钟极性 | **0**（Mode 0） |
| 2 | **MSTR** | 主设备选择 | **1**（主模式） |
| 5:3 | **BR[2:0]** | 波特率控制 | **001**（4 分频） |
| 6 | **SPE** | SPI 使能 | **1**（启动） |
| 7 | **LSBFIRST** | 数据位序 | **0**（MSB 先行） |
| 8 | **SSI** | 内部从设备选择 | **1**（主模式） |
| 9 | **SSM** | 软件从设备管理 | **1**（软件控制） |
| 10 | **RXONLY** | 只接收模式 | **0**（全双工） |
| 11 | **DFF** | 数据帧格式 | **0**（8 位） |
| 12 | **CRCNEXT** | 下一数据是 CRC | 0 |
| 13 | **CRCEN** | CRC 使能 | 0 |
| 14 | **BIDIOE** | 双向输出使能 | 0 |
| 15 | **BIDIMODE** | 双向数据模式 | **0**（双线全双工） |

### 4.2 各配置位详解

#### ① 主从模式（MSTR）

```
CR1.MSTR：
  0 = 从模式
  1 = 主模式 ← 我们需要这个

STM32 与 W25Q32 通信：
  STM32 = 主设备 → MSTR = 1
  W25Q32 = 从设备
```

#### ② 波特率控制（BR[2:0]）

```
时钟频率 = fPCLK / 分频系数

CR1.BR[2:0] | 分频系数 | APB2(72MHz)结果 | APB1(36MHz)结果
    000     |    2     | 36 MHz（太快） | 18 MHz
    001     |    4     | 18 MHz ✅      | 9 MHz
    010     |    8     | 9 MHz          | 4.5 MHz
    011     |    16    | 4.5 MHz        | 2.25 MHz
    100     |    32    | 2.25 MHz       | ...
    101     |    64    | 1.125 MHz      | ...
    110     |    128   | 562.5 kHz      | ...
    111     |    256   | 281.25 kHz     | ...

W25Q32 最高支持 18MHz：
  → APB2（72MHz）：选择 4 分频 → 18MHz ✅
  → APB1（36MHz）：选择 2 分频 → 18MHz ✅

我们选 BR = 001（4 分频）→ 18MHz
```

#### ③ 时钟极性和相位（CPOL/CPHA）

```
Mode 0（默认，最常用）：
  CPOL = 0（空闲时 SCK 为低电平）
  CPHA = 0（第一个跳变沿采样 = 上升沿采样）

W25Q32 支持 Mode 0 和 Mode 3：
  → 直接使用 Mode 0 即可
  → CPOL = 0, CPHA = 0
```

#### ④ 数据帧格式（DFF）

```
CR1.DFF：
  0 = 8 位数据帧（每次传输 1 字节）← 我们用这个
  1 = 16 位数据帧（每次传输 2 字节）
```

#### ⑤ 数据位序（LSBFIRST）

```
CR1.LSBFIRST：
  0 = MSB 先行（高位优先）← 我们用这个（W25Q32 要求）
  1 = LSB 先行（低位优先）
```

#### ⑥ 软件从设备管理（SSM + SSI）

```
CR1.SSM = 1：启用软件从设备管理
  → 不看硬件 NSS 引脚的输入信号
  → 由 SSI 位决定内部 NSS 电平

CR1.SSI = 1：内部 NSS = 高电平
  → 主模式：不被选中（正确）
  → 等效于硬件 NSS 接 3.3V
```

#### ⑦ SPI 使能（SPE）

```
CR1.SPE：
  0 = SPI 禁用
  1 = SPI 使能 ← 所有配置完成后，最后置 1 启动
```

## 六、SR 状态寄存器详解

| 位 | 名称 | 功能 | 清零方式 |
|:--:|------|------|---------|
| 0 | **RXNE** | 接收缓冲区非空（有数据可读） | 读 DR 自动清零 |
| 1 | **TXE** | 发送缓冲区为空（可写入数据） | 写 DR 自动清零 |
| 2 | CRCERR | CRC 错误标志 | 软件写 0 清零 |
| 3 | UDR | 下溢标志 | 读 SR + 访问 DR |
| 4 | MODF | 模式错误 | 读 SR + 写 CR1 |
| 5 | OVR | 溢出标志 | 读 SR + 读 DR |
| 6 | BSY | 忙标志 | 由硬件自动管理 |
| 7 | FRE | 帧格式错误 | 读 SR + 读 DR |

### 6.1 关键状态位

```
① TXE（Bit 1）— 发送缓冲区空
   = 0：发送缓冲区非空（还有数据未发出，不能写入）
   = 1：发送缓冲区为空（可以写入新数据到 DR）
   → 写 DR 时自动清零

② RXNE（Bit 0）— 接收缓冲区非空
   = 0：接收缓冲区空（没有数据可读）
   = 1：接收缓冲区非空（有数据可从 DR 读取）
   → 读 DR 时自动清零

③ BSY（Bit 6）— 忙标志
   = 0：SPI 空闲
   = 1：SPI 正在通信（正在发送或接收）
   → 只读，硬件自动管理
```

## 七、DR 数据寄存器

```
16 位寄存器（实际使用取决于 DFF 配置）

写入 DR：
  → 数据进入发送缓冲区（TDR）
  → 自动启动发送
  → TXE 自动清零

读取 DR：
  → 从接收缓冲区（RDR）读取数据
  → RXNE 自动清零

注意：
  → 写入和读取共用同一个地址
  → 写入 = 发送，读取 = 接收
  → 底层 TDR 和 RDR 是独立的
```

## 八、硬件 SPI 交换字节函数

### 8.1 函数实现

```c
/**
 * @brief  通过硬件 SPI 交换一个字节（全双工）
 * @param  byte: 要发送的字节
 * @retval 接收到的字节
 *
 * 流程：
 *   ① 等待 TXE=1（发送缓冲区为空）
 *   ② 写入 DR（启动发送，同时清零 TXE）
 *   ③ 等待 RXNE=1（接收缓冲区有数据）
 *   ④ 读取 DR（获取接收数据，同时清零 RXNE）
 */
uint8_t SPI_SwapByte(uint8_t byte)
{
    /* 1. 等待发送缓冲区为空 */
    while (!(SPI1->SR & SPI_SR_TXE));  // TXE = 0 则等待

    /* 2. 写入数据到 DR（启动发送）*/
    SPI1->DR = byte;

    /* 3. 等待接收缓冲区非空 */
    while (!(SPI1->SR & SPI_SR_RXNE)); // RXNE = 0 则等待

    /* 4. 读取接收到的数据 */
    return SPI1->DR;
}
```

### 8.2 交换过程时序

```
┌─────────────────────────────────────────────────┐
│  ① while (!(SR & TXE))                          │
│     → 等待发送缓冲区为空                          │
│     → TXE=1 说明可以写入新数据                    │
├─────────────────────────────────────────────────┤
│  ② DR = byte                                    │
│     → 写入数据到发送缓冲区                        │
│     → TXE 自动清零                               │
│     → 硬件自动启动 8 个时钟周期发送数据             │
│     → 同时自动接收从设备返回的数据                  │
├─────────────────────────────────────────────────┤
│  ③ while (!(SR & RXNE))                         │
│     → 等待接收缓冲区非空                          │
│     → RXNE=1 说明已收到数据                       │
├─────────────────────────────────────────────────┤
│  ④ return DR                                    │
│     → 读取接收缓冲区的数据                        │
│     → RXNE 自动清零                              │
└─────────────────────────────────────────────────┘
```

### 8.3 与软件模拟对比

| 对比项 | 软件模拟 SPI | 硬件 SPI |
|--------|-------------|---------|
| 发送前检查 | 不需要（GPIO 直接翻转） | **等待 TXE=1** |
| 写入数据 | MOSI_HIGH/LOW + 移位 | **写 DR** |
| 接收数据 | MISO_READ + 移位 | **读 DR** |
| 接收后检查 | 不需要 | **等待 RXNE=1** |
| CPU 占用 | 高（逐位控制） | **低（硬件自动移位）** |
| 速度 | 慢 | **快** |

## 九、SPI 初始化配置流程

```c
void SPI_Init(void)
{
    /* 1. 开启时钟 */
    RCC->APB2ENR |= RCC_APB2ENR_SPI1EN;   // SPI1 时钟
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;   // GPIOA 时钟
    RCC->APB2ENR |= RCC_APB2ENR_IOPCEN;   // GPIOC 时钟

    /* 2. 配置 GPIO（复用功能）*/
    // PA5(SCK)、PA7(MOSI)：复用推挽输出，50MHz
    // PA6(MISO)：浮空输入
    // PC13(CS)：通用推挽输出

    /* 3. 配置 SPI CR1 */
    SPI1->CR1 = 0;                         // 先清零

    SPI1->CR1 |= SPI_CR1_MSTR;            // 主模式
    SPI1->CR1 |= SPI_CR1_SSM;             // 软件从设备管理
    SPI1->CR1 |= SPI_CR1_SSI;             // 内部 NSS = 高（主设备）
    SPI1->CR1 |= SPI_CR1_BR_0;            // 波特率 001 = 4 分频 → 18MHz
    // CPOL=0, CPHA=0（Mode 0，默认值）
    // DFF=0（8 位，默认值）
    // LSBFIRST=0（MSB 先行，默认值）
    // BIDIMODE=0（双线全双工，默认值）

    /* 4. 使能 SPI */
    SPI1->CR1 |= SPI_CR1_SPE;             // SPI 使能
}
```

## 十、CR1 配置位速查表

```
CR1 = 0x0000 0000（初始清零）

需要置 1 的位：
  Bit 2  MSTR    = 1  → 主模式
  Bit 3  BR[0]   = 1  ┐
  Bit 4  BR[1]   = 0  │ → BR = 001（4 分频）
  Bit 5  BR[2]   = 0  ┘
  Bit 8  SSI     = 1  → 内部从设备选择 = 高电平
  Bit 9  SSM     = 1  → 软件从设备管理
  Bit 6  SPE     = 1  → SPI 使能（最后开启）

保持 0 的位（默认值）：
  Bit 0  CPHA    = 0  → Mode 0
  Bit 1  CPOL    = 0  → Mode 0
  Bit 7  LSBFIRST= 0  → MSB 先行
  Bit 10 RXONLY  = 0  → 全双工
  Bit 11 DFF     = 0  → 8 位数据帧
  Bit 15 BIDIMODE= 0  → 双线双向

最终 CR1 = 0x0344（二进制：0000 0011 0100 0100）
```

## 十一、SPI 支持的其他功能（了解）

### 11.1 单线半双工模式

```
CR1.BIDIMODE = 1：
  → 单线双向模式（半双工）
  → 只用一根数据线（MOSI 或 MISO）

CR1.BIDIOE：
  0 = 禁止输出（只接收）
  1 = 使能输出（只发送）

配合使用：
  BIDIMODE=1, BIDIOE=1 → 只发送（MOSI 输出）
  BIDIMODE=1, BIDIOE=0 → 只接收（MISO 输入）

默认 BIDIMODE=0 → 双线全双工（我们用这个）
```

### 11.2 只接收模式

```
CR1.RXONLY = 1：
  → 只接收模式
  → 发送部分被禁用
  → MISO 上的数据自动接收
  → 适合只读场景（如 ADC 读取）
```

### 11.3 CRC 校验

```
CR1.CRCEN = 1：启用 CRC 校验
CR1.CRCNEXT = 1：下一个发送的数据来自 CRC 寄存器

CRCPR：CRC 多项式寄存器
RXCRCR：接收 CRC 寄存器
TXCRCR：发送 CRC 寄存器

一般通信场景不需要，可靠性要求高时使用
```

### 11.4 I2S 模式

```
SPI 接口可切换为 I2S 音频接口：
  → 用于音频数据传输
  → I2SCFGR：I2S 配置寄存器
  → I2SPR：I2S 预分频寄存器
  → 支持 PCM/DPCM 音频格式

我们不需要使用
```

## 十二、完整读写 W25Q32 流程

```
初始化：
  ① 开启 SPI1 + GPIO 时钟
  ② 配置 GPIO（PA5/PA7 复用推挽，PA6 浮空输入，PC13 推挽输出）
  ③ 配置 SPI CR1（主模式/软件NSS/Mode0/4分频/8位）
  ④ 使能 SPI（SPE=1）
  ⑤ CS 默认拉高（PC13 输出高电平）

读取 JEDEC ID（验证通信）：
  ① CS 拉低
  ② SPI_SwapByte(0x9F)    → 发送读 ID 指令
  ③ SPI_SwapByte(0xFF)    → 接收制造商 ID（发任意值）
  ④ SPI_SwapByte(0xFF)    → 接收存储类型
  ⑤ SPI_SwapByte(0xFF)    → 接收容量
  ⑥ CS 拉高

写入数据：
  ① CS 拉低 → SPI_SwapByte(0x06) → CS 拉高（写使能）
  ② CS 拉低
  ③ SPI_SwapByte(0x02)          → 页写指令
  ④ SPI_SwapByte(地址高字节)     → 24 位地址
  ⑤ SPI_SwapByte(地址中字节)
  ⑥ SPI_SwapByte(地址低字节)
  ⑦ SPI_SwapByte(数据...)       → 写入数据（≤256 字节）
  ⑧ CS 拉高
  ⑨ 等待 BUSY=0（读状态寄存器）

读取数据：
  ① CS 拉低
  ② SPI_SwapByte(0x03)          → 读数据指令
  ③ SPI_SwapByte(地址高字节)     → 24 位地址
  ④ SPI_SwapByte(地址中字节)
  ⑤ SPI_SwapByte(地址低字节)
  ⑥ data = SPI_SwapByte(0xFF)   → 接收数据（发 0xFF 占位）
  ⑦ CS 拉高

段擦除：
  ① CS 拉低 → SPI_SwapByte(0x06) → CS 拉高（写使能）
  ② CS 拉低
  ③ SPI_SwapByte(0x20)          → 段擦除指令
  ④ SPI_SwapByte(地址高字节)     → 段地址
  ⑤ SPI_SwapByte(地址中字节)
  ⑥ SPI_SwapByte(地址低字节)
  ⑦ CS 拉高
  ⑧ 等待 BUSY=0
```

## 十三、关键概念速查

| 概念 | 说明 |
|------|------|
| MSTR | 主设备选择位（CR1 Bit 2） |
| BR[2:0] | 波特率控制（CR1 Bit 5:3），001=4分频 |
| CPOL | 时钟极性（CR1 Bit 1），0=空闲低 |
| CPHA | 时钟相位（CR1 Bit 0），0=第一个跳变沿采样 |
| SSM | 软件从设备管理（CR1 Bit 9） |
| SSI | 内部从设备选择（CR1 Bit 8），1=主设备 |
| SPE | SPI 使能（CR1 Bit 6） |
| TXE | 发送缓冲区空标志（SR Bit 1），写 DR 清零 |
| RXNE | 接收缓冲区非空标志（SR Bit 0），读 DR 清零 |
| BSY | 忙标志（SR Bit 6），只读 |
| DR | 数据寄存器，写=发送，读=接收 |
| SSOE | SS 输出使能（CR2 Bit 2），广播功能 |
| NSS/CS | 片选信号，我们用 PC13 GPIO 模拟 |
| Mode 0 | CPOL=0, CPHA=0（默认最常用） |

## 十四、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| SPI 无输出 | SPE 未使能 | 最后置 CR1.SPE=1 |
| 从机无响应 | CS 未拉低 | PC13 输出低电平 |
| 数据全 0xFF | SCK 频率太高 | 增大分频系数 |
| 数据错位 | Mode 不匹配 | 确认 Mode 0 |
| 一直等待 TXE | SPI 未使能 | 检查 SPE 位 |
| 一直等待 RXNE | 从设备未响应 | 检查接线和 CS |
| BSY 一直为 1 | 通信未结束 | 等待或检查从设备 |
| MSTR 配置无效 | SPE 已开启 | 先配 MSTR，最后开 SPE |
