# 第六章 FSMC 控制器 — 硬件电路设计与寄存器配置 笔记

---

## 一、硬件电路连接

### 1.1 IS62WV51216 与 STM32 的连线关系

```
STM32 通过 FSMC 的 GPIO 复用功能连接 IS62WV51216：

引脚          FSMC 信号         SRAM 引脚         功能
──────────────────────────────────────────────────────────
地址线        A[18:0]          A0 ~ A18          19 根地址线
数据线        D[15:0]          IO0 ~ IO15        16 根数据线
片选          NE3              CS1               片选（低有效）
读使能        NOE              OE                读使能（低有效）
写使能        NWE              WE                写使能（低有效）
高字节使能    NBL1             UB                高字节屏蔽（低有效）
低字节使能    NBL0             LB                低字节屏蔽（低有效）
电源          VDD              VDD               3.3V
地            GND              GND               地
```

### 1.2 片选信号与地址空间

```
IS62WV51216 的 CS1 连接的是 NE3：
  → 对应 FSMC Bank 1 的第 3 个子区（Bank1-3）
  → 地址范围：0x6800_0000 ~ 0x6BFF_FFFF
  → 大小：64 MB

NE 信号与地址空间对应关系：

  片选    连接的存储器        地址范围                   大小
  ──────────────────────────────────────────────────────────
  NE1     NOR Flash/SRAM 1   0x6000_0000 ~ 0x63FF_FFFF   64 MB
  NE2     NOR Flash/SRAM 2   0x6400_0000 ~ 0x67FF_FFFF   64 MB
  NE3     NOR Flash/SRAM 3   0x6800_0000 ~ 0x6BFF_FFFF   64 MB
  NE4     NOR Flash/SRAM 4   0x6C00_0000 ~ 0x6FFF_FFFF   64 MB

实际 SRAM 芯片只有 1 MB，但映射了 64 MB 的地址空间
→ 只使用其中 1 MB，剩余地址空闲
→ 实际可用地址：0x6800_0000 ~ 0x680F_FFFF
```

### 1.3 FSMC 引脚对应的 GPIO

```
NE3 对应的 GPIO 引脚：PG10
→ 需要将 PG10 配置为复用推挽输出（FSMC 功能）

所有 FSMC 引脚均为 GPIO 复用功能：
→ 地址线、数据线、控制信号全部配置为 AF_PP（复用推挽输出）
```

## 二、使用的寄存器

### 2.1 寄存器总览

```
FSMC NOR Flash / SRAM 配置寄存器：

Bank 1 有 4 个子区，每个子区对应 2 个寄存器：

  子区    配置寄存器（BCR）   时序寄存器（BTR）
  ──────────────────────────────────────────
  1       BCR1              BTR1
  2       BCR2              BTR2
  3       BCR3              BTR3    ← 我们使用这个
  4       BCR4              BTR4

  + BWTR1 ~ BWTR4（写时序寄存器，扩展模式使用，模式 1 不用）

我们使用 NE3（Bank1-3）：
  → 只需配置 BCR3 和 BTR3
  → 使用模式 1 → 读写合一 → 不需要 BWTR3
```

### 2.2 源码中的寄存器定义

```c
/* 源码中 BCR 和 BTR 合并定义为一个数组 */
/* 数组名称：BTCR[8] */

/* 数组布局 */
BTCR[0] = BCR1    /* Bank1-1 配置 */
BTCR[1] = BTR1    /* Bank1-1 时序 */
BTCR[2] = BCR2    /* Bank1-2 配置 */
BTCR[3] = BTR2    /* Bank1-2 时序 */
BTCR[4] = BCR3    /* Bank1-3 配置 ← 我们要操作的 */
BTCR[5] = BTR3    /* Bank1-3 时序 ← 我们要操作的 */
BTCR[6] = BCR4    /* Bank1-4 配置 */
BTCR[7] = BTR4    /* Bank1-4 时序 */

/* 操作 BCR3 和 BTR3 */
FSMC_Bank1->BTCR[4]  /* = BCR3 */
FSMC_Bank1->BTCR[5]  /* = BTR3 */
```

```
为什么合为一个数组？

  → 8 个寄存器连续存放在地址空间中
  → 每个子区的 BCR 和 BTR 紧密排列
  → 不需要为每个子区单独定义结构体
  → 直接用数组索引访问即可
  → BTCR[4] = BCR3, BTCR[5] = BTR3
```

## 三、BCR3 配置寄存器详解

### 3.1 BCR3 关键位域

| 位 | 名称 | 功能 | 配置值 | 说明 |
|:--:|------|------|:------:|------|
| 0 | **MBKEN** | 存储器块使能 | **1** | 开启 Bank1-3 |
| 1 | **MUXEN** | 地址/数据复用使能 | **0** | 不使用复用模式 |
| 3:2 | **MTYP[1:0]** | 存储器类型 | **00** | SRAM / ROM |
| 5:4 | **MWID[1:0]** | 数据总线宽度 | **01** | 16 位 |
| 6 | **FACCEN** | Flash 访问使能 | **0** | 禁止（SRAM 不需要） |
| 8 | **BURSTEN** | 突发传输使能 | 0 | 不使用（异步模式） |
| 9 | **WAITPOL** | 等待信号极性 | 0 | 不使用 |
| 10 | **WRAPMOD** | 非对齐突发模式 | 0 | 不使用 |
| 11 | **WAITCFG** | 等待配置 | 0 | 不使用 |
| 12 | **WREN** | 写使能 | **1** | 允许写入 |
| 13 | **WAITEN** | 等待使能 | 0 | 不使用 |
| 14 | **EXTMOD** | 扩展模式使能 | **0** | 模式 1（不使用扩展） |
| 15 | **ASYNCWAIT** | 异步等待 | 0 | 不使用 |
| 19:16 | — | 保留 | — | — |

### 3.2 各配置位详解

#### ① MBKEN — 存储器块使能（Bit 0）

```
BCR.MBKEN：
  0 = 存储器块禁用
  1 = 存储器块使能 ← 我们需要这个

说明：
  → 复位后只有 Bank 1（存储器块 1）默认使能
  → 我们使用的是 Bank1-3（NE3）
  → 需要显式使能该存储器块
  → 配置：MBKEN = 1
```

#### ② MUXEN — 地址/数据复用使能（Bit 1）

```
BCR.MUXEN：
  0 = 禁用复用（独立地址线和数据线）← 我们用这个
  1 = 使能复用（地址线和数据线共用）

说明：
  → 我们的 SRAM 有独立的地址线和数据线
  → 不需要地址/数据复用
  → 配置：MUXEN = 0

注意：
  → 复位后默认 MUXEN = 1（复用模式）
  → 必须显式配置为 0
  → 否则地址线工作不正常
```

#### ③ MTYP — 存储器类型（Bit 3:2）

```
BCR.MTYP[1:0]：
  00 = SRAM 或 ROM    ← 我们需要这个
  01 = PSRAM
  10 = NOR Flash

说明：
  → 我们扩展的是 SRAM 芯片
  → 配置：MTYP = 00

注意：
  → 复位后 Bank 1 默认 MTYP = 10（NOR Flash）
  → 必须显式改为 00（SRAM/ROM）
```

#### ④ MWID — 数据总线宽度（Bit 5:4）

```
BCR.MWID[1:0]：
  00 = 8 位
  01 = 16 位   ← 我们用这个（默认值）
  10 = 保留（不支持 32 位）
  11 = 保留

说明：
  → IS62WV51216 数据宽度为 16 位
  → 复位后默认就是 01（16 位）
  → 可以不配，但建议显式配置
```

#### ⑤ FACCEN — Flash 访问使能（Bit 6）

```
BCR.FACCEN：
  0 = 禁止 Flash 访问 ← 我们需要这个
  1 = 允许 Flash 访问

说明：
  → 我们连接的是 SRAM，不是 Flash
  → 禁止 Flash 访问功能
  → 配置：FACCEN = 0
```

#### ⑥ WREN — 写使能（Bit 12）

```
BCR.WREN：
  0 = 禁止写入
  1 = 允许写入 ← 我们需要这个

说明：
  → 复位后默认 WREN = 1（允许写入）
  → 可以不配，但建议显式配置
  → 确保写操作可以正常进行
```

#### ⑦ EXTMOD — 扩展模式使能（Bit 14）

```
BCR.EXTMOD：
  0 = 不使用扩展模式（模式 1）← 我们用这个
  1 = 使用扩展模式（模式 A/B/C/D）

说明：
  → 我们使用最简单的模式 1
  → 读写时序共用 BTR3，不需要 BWTR3
  → 配置：EXTMOD = 0

注意：
  → 复位后默认 EXTMOD = 0
  → 但建议显式配置确认
```

### 3.3 BCR3 配置总结

```
BCR3 配置值：

  MBKEN   = 1   → 使能存储器块
  MUXEN   = 0   → 不使用地址/数据复用
  MTYP    = 00  → SRAM/ROM 类型
  MWID    = 01  → 16 位数据宽度
  FACCEN  = 0   → 禁止 Flash 访问
  WREN    = 1   → 允许写入
  EXTMOD  = 0   → 模式 1（不使用扩展模式）

需要显式配置的位：
  → MBKEN = 1（使能）
  → MUXEN = 0（默认为 1，必须改）
  → MTYP = 00（默认为 NOR Flash，必须改）
  → FACCEN = 0（禁止 Flash 访问）

可使用默认值的位：
  → MWID = 01（默认就是 16 位）
  → WREN = 1（默认允许写入）
  → EXTMOD = 0（默认不使用扩展模式）
```

## 四、BTR3 时序寄存器详解

### 4.1 BTR3 关键位域

| 位 | 名称 | 功能 | 配置值 | 说明 |
|:--:|------|------|:------:|------|
| 3:0 | **ADDSET** | 地址建立时间 | **0x0** | 最小值（1 个周期） |
| 7:4 | **ADDHLD** | 地址保持时间 | 0x0 | 模式 1 不需要 |
| 15:8 | **DATASET** | 数据建立时间 | **0x02 ~ 0x47** | ≥ 40 ns |
| 19:16 | **BUSTURN** | 总线转换周期 | 0x0 | 不需要 |
| 23:20 | **CLKDIV** | 时钟分频 | 0x0 | 异步模式不需要 |
| 27:24 | **DATLAT** | 数据延迟 | 0x0 | 异步模式不需要 |
| 29:28 | **ACCMOD** | 访问模式 | 0x0 | 模式 1 不需要 |
| 31:30 | — | 保留 | — | — |

### 4.2 各配置位详解

#### ① ADDSET — 地址建立时间（Bit 3:0）

```
BTR.ADDSET[3:0]：
  地址建立时间 = ADDSET + 1 个 HCLK 周期

配置分析：
  → 芯片要求：tSA ≥ 0 ns（无下限）
  → ADDSET = 0 → 实际时间 = 1 × 13.9 ns ≈ 13.9 ns
  → 满足要求

配置：ADDSET = 0x0
```

#### ② ADDHLD — 地址保持时间（Bit 7:4）

```
BTR.ADDHLD[3:0]：
  地址保持时间 = ADDHLD + 1 个 HCLK 周期

配置分析：
  → 模式 1 下不需要地址保持时间
  → 仅在模式 D 或复用模式下使用
  → 配置：ADDHLD = 0x0（或不配）
```

#### ③ DATASET — 数据建立时间（Bit 15:8）

```
BTR.DATASET[7:0]：
  数据建立时间 = DATASET + 1 个 HCLK 周期

配置分析：
  → 芯片要求：tPWE ≥ 40 ns（WE 有效宽度）
  → 对应模式 1 写时序中的 WE 有效时间
  → HCLK = 72 MHz → 1 周期 ≈ 13.9 ns

  DATASET 计算：
    DATASET + 1 ≥ 40 / 13.9 ≈ 2.88
    DATASET ≥ 1.88 → DATASET ≥ 2

  推荐配置值：
    DATASET = 2  → 3 × 13.9 = 41.7 ns  ✅（刚好满足）
    DATASET = 3  → 4 × 13.9 = 55.6 ns  ✅（有余量）
    DATASET = 71 → 72 × 13.9 = 1000 ns ✅（1 μs，保守）

配置：DATASET = 0x02（最小满足）或 0x03（有余量）
       或直接配 0x47 = 71（一微秒，绝对安全）
```

#### ④ BUSTURN — 总线转换周期（Bit 19:16）

```
BTR.BUSTURN[3:0]：
  总线转换周期

配置分析：
  → 仅适用于总线复用模式的闪存操作
  → 我们不使用复用模式
  → 配置：BUSTURN = 0x0
```

#### ⑤ CLKDIV — 时钟分频（Bit 23:20）

```
BTR.CLKDIV[3:0]：
  同步模式下的时钟分频系数

配置分析：
  → 仅同步模式需要
  → SRAM 只支持异步模式
  → 配置：CLKDIV = 0x0（不起作用）
```

#### ⑥ DATLAT — 数据延迟（Bit 27:24）

```
BTR.DATLAT[3:0]：
  同步突发模式下的数据延迟

配置分析：
  → 仅同步模式需要
  → SRAM 只支持异步模式
  → 配置：DATLAT = 0x0（不起作用）
```

#### ⑦ ACCMOD — 访问模式（Bit 29:28）

```
BTR.ACCMOD[1:0]：
  00 = 模式 A
  01 = 模式 B
  10 = 模式 C
  11 = 模式 D

配置分析：
  → 仅当 BCR.EXTMOD = 1 时有效
  → 我们使用模式 1（EXTMOD = 0）
  → 此位不起作用
  → 配置：ACCMOD = 0x0
```

### 4.3 BTR3 配置总结

```
BTR3 配置值：

  ADDSET  = 0x00（4 位）→ 地址建立 = 1 个周期 ≈ 13.9 ns
  ADDHLD  = 0x00（4 位）→ 模式 1 不需要
  DATASET = 0x02（8 位）→ 数据建立 = 3 个周期 ≈ 41.7 ns ≥ 40 ns ✅
  BUSTURN = 0x00（4 位）→ 不需要
  CLKDIV  = 0x00（4 位）→ 异步模式不需要
  DATLAT  = 0x00（4 位）→ 异步模式不需要
  ACCMOD  = 0x00（2 位）→ 模式 1 不需要

核心配置：
  → ADDSET = 0（最小值即可）
  → DATASET = 2（满足 40 ns 最低要求）
  → 其余全部为 0
```

## 六、模式 1 时序配置总结

### 6.1 读时序配置

```
模式 1 读时序特点：
  → NOE 始终保持低电平有效（不随地址建立变化）
  → 地址建立后直接进入数据建立阶段
  → 配置参数全部由 BTR3 控制

读时序参数：
  AddSet  = ADDSET + 1 = 1 个周期 ≈ 13.9 ns
  DataSet = DATASET + 1 = 3 个周期 ≈ 41.7 ns
  数据保持 = 1 个周期（硬件自动保证）
```

### 6.2 写时序配置

```
模式 1 写时序特点：
  → NWE 在地址建立后拉低
  → 数据由 FSMC 驱动到数据总线
  → WE 有效宽度 = DataSet + 1 个周期
  → 配置参数全部由 BTR3 控制（与读共用）

写时序参数：
  AddSet  = ADDSET + 1 = 1 个周期 ≈ 13.9 ns
  DataSet = DATASET + 1 = 3 个周期 ≈ 41.7 ns ≥ 40 ns（tPWE 要求）✅
  数据保持 = NWE 关闭后 ≥ 1 个周期（硬件自动保证）
```

### 6.3 时序配置验证

```
IS62WV51216 时序要求 vs FSMC 配置：

  参数        芯片要求        FSMC 配置        满足？
  ──────────────────────────────────────────────────
  tSA         ≥ 0 ns         13.9 ns          ✅
  tPWE        ≥ 40 ns        41.7 ns          ✅
  tRC         55 ns（周期）   ~69 ns           ✅
  tWC         55 ns（周期）   ~69 ns           ✅
```

## 七、完整配置代码结构

### 7.1 配置步骤

```c
void FSMC_SRAM_Init(void)
{
    /* 1. 开启时钟 */
    // RCC->AHBENR  |= RCC_AHBENR_FSMCEN;   // FSMC 时钟
    // RCC->APB2ENR |= RCC_APB2ENR_IOPxEN;  // 相关 GPIO 时钟

    /* 2. 配置 GPIO（复用推挽输出 / 浮空输入）*/
    // 地址线 A[18:0] → 复用推挽输出
    // 数据线 D[15:0] → 复用推挽输出
    // 控制线 NE/NOE/NWE/NBL → 复用推挽输出

    /* 3. 配置 BCR3 */
    FSMC_Bank1->BTCR[4] = 0;
    FSMC_Bank1->BTCR[4] |= (1 << 0);    // MBKEN = 1（使能存储器块）
    FSMC_Bank1->BTCR[4] &= ~(1 << 1);   // MUXEN = 0（不使用复用）
    FSMC_Bank1->BTCR[4] &= ~(3 << 2);   // MTYP = 00（SRAM/ROM）
    FSMC_Bank1->BTCR[4] |= (1 << 4);    // MWID = 01（16 位）
    FSMC_Bank1->BTCR[4] &= ~(1 << 6);   // FACCEN = 0（禁止 Flash）
    FSMC_Bank1->BTCR[4] |= (1 << 12);   // WREN = 1（允许写入）
    FSMC_Bank1->BTCR[4] &= ~(1 << 14);  // EXTMOD = 0（模式 1）

    /* 4. 配置 BTR3 */
    FSMC_Bank1->BTCR[5] = 0;
    FSMC_Bank1->BTCR[5] |= (0 << 0);    // ADDSET = 0（最小值）
    FSMC_Bank1->BTCR[5] |= (2 << 8);    // DATASET = 2（≥ 40 ns）
    // 其余位保持为 0
}
```

### 7.2 BCR3 配置值速算

```
逐位计算 BCR3 的值：

  Bit 15 保留       = 0
  Bit 14 EXTMOD     = 0  （模式 1）
  Bit 13 保留       = 0
  Bit 12 WREN       = 1  （写使能）
  Bit 11 保留       = 0
  Bit 10 保留       = 0
  Bit 9  保留       = 0
  Bit 8  保留       = 0
  Bit 7  保留       = 0
  Bit 6  FACCEN     = 0  （禁止 Flash 访问）
  Bit 5  MWID[1]    = 0  ┐
  Bit 4  MWID[0]    = 1  ┘ 16 位数据宽度
  Bit 3  MTYP[1]    = 0  ┐
  Bit 2  MTYP[0]    = 0  ┘ SRAM/ROM 类型
  Bit 1  MUXEN      = 0  （不使用复用）
  Bit 0  MBKEN      = 1  （使能存储器块）

  BCR3 = 0001 0000 0001 0001 = 0x1011
```

### 7.3 BTR3 配置值速算

```
逐位计算 BTR3 的值：

  Bit 31:30 保留     = 00
  Bit 29:28 ACCMOD   = 00 （模式 1 不需要）
  Bit 27:24 DATLAT   = 0000（异步不需要）
  Bit 23:20 CLKDIV   = 0000（异步不需要）
  Bit 19:16 BUSTURN  = 0000（不需要）
  Bit 15:8  DATASET  = 00000010（= 2，≥ 40 ns）
  Bit 7:4   ADDHLD   = 0000（模式 1 不需要）
  Bit 3:0   ADDSET   = 0000（最小值）

  BTR3 = 0000 0000 0000 0010 0000 0000 0000 0000 = 0x00000200
```

## 八、模式 1 vs 其他模式配置对比

### 8.1 模式 1 配置要点

```
模式 1（最简单）：
  → BCR.EXTMOD = 0（不使用扩展模式）
  → BTR 同时控制读和写时序
  → 不需要 BWTR 寄存器
  → 只需配置 ADDSET 和 DATASET
```

### 8.2 扩展模式配置要点（模式 A/B/C/D）

```
扩展模式：
  → BCR.EXTMOD = 1（开启扩展模式）
  → BTR 控制读时序（ADDSET + DATASET）
  → BWTR 控制写时序（ADDSET + DATASET）
  → BTR.ACCMOD 选择具体模式（A/B/C/D）
  → 读写可以独立配置不同的时序参数
```

## 十、关键概念速查

| 概念 | 说明 |
|------|------|
| NE3 | Bank 1 第 3 子区片选信号，对应地址 0x6800_0000 ~ 0x6BFF_FFFF |
| PG10 | NE3 对应的 GPIO 引脚 |
| BCR | Bus Configuration Register，总线配置寄存器 |
| BTR | Bus Timing Register，总线时序寄存器 |
| BWTR | Bus Write Timing Register，总线写时序寄存器（扩展模式） |
| BTCR | 源码中 BCR 和 BTR 合并定义的数组 |
| BTCR[4] | = BCR3（Bank1-3 配置寄存器） |
| BTCR[5] | = BTR3（Bank1-3 时序寄存器） |
| MBKEN | 存储器块使能位，置 1 开启对应 Bank |
| MUXEN | 地址/数据复用使能，模式 1 设为 0 |
| MTYP | 存储器类型：00=SRAM/ROM, 01=PSRAM, 10=NOR Flash |
| MWID | 数据总线宽度：00=8 位, 01=16 位 |
| FACCEN | Flash 访问使能，SRAM 设为 0 |
| WREN | 写使能，置 1 允许写入 |
| EXTMOD | 扩展模式使能，模式 1 设为 0 |
| ADDSET | 地址建立时间 = ADDSET + 1 个 HCLK 周期 |
| DATASET | 数据建立时间 = DATASET + 1 个 HCLK 周期 |
| ADDHLD | 地址保持时间，模式 1 不需要 |
| ACCMOD | 访问模式选择（A/B/C/D），EXTMOD=0 时不起作用 |
| 模式 1 | 最简单模式，读写合一，只用 BTR 配置时序 |
| BCR3 = 0x1011 | MBKEN=1, MWID=01, WREN=1, 其余=0 |
| BTR3 = 0x00000200 | ADDSET=0, DATASET=2, 其余=0 |

## 十一、常见问题

| 问题                   | 解答                                     |
| -------------------- | -------------------------------------- |
| IS62WV51216 连接哪个 NE？ | **NE3**，对应 PG10 引脚                     |
| 地址空间是哪一段？            | **0x6800_0000 ~ 0x6BFF_FFFF**（Bank1-3） |
| 用哪两个寄存器？             | **BCR3**（BTCR[4]）和 **BTR3**（BTCR[5]）   |
| 为什么 MUXEN 必须配为 0？    | 复位后默认为 1（复用模式），必须关闭                    |
| 为什么 MTYP 必须配？        | 复位后默认为 NOR Flash，必须改为 SRAM/ROM         |
| MWID 用默认值行吗？         | 可以（默认就是 16 位），但建议显式配置                  |
| DATASET 至少配多少？       | **≥ 2**（3 个周期 ≈ 41.7 ns ≥ 40 ns）       |
| ADDSET 配多少？          | **0**（芯片无下限要求）                         |
| 模式 1 需要 BWTR 吗？      | **不需要**，读写共用 BTR                       |
| 模式 1 需要 ACCMOD 吗？    | **不需要**，EXTMOD=0 时不起作用                 |
| BCR3 配置值是多少？         | **0x1011**                             |
| BTR3 配置值是多少？         | **0x00000200**（ADDSET=0, DATASET=2）    |
