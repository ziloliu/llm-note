# 第七章 LCD（液晶显示器）— 硬件电路设计与引脚连接 笔记

---

## 一、LCD 显示案例目标

### 1.1 功能需求

```
使用 STM32 的 FSMC 模块控制液晶屏：
  → 显示英文字符
  → 显示汉字
  → 显示自定义图形/信息

核心思路：
  → 将 LCD 的显存（GRAM）视为 FSMC 扩展的存储器
  → 通过 FSMC 发送命令和数据
  → 控制 ILI9486 驱动 320×480 的 TFT LCD 显示
```

---

## 二、LCD 背光光源

### 2.1 背光类型

```
LCD 显示屏需要背光光源才能看到画面：

① CCFL（冷阴极射线管）背光（已淘汰）
   → 本质是荧光管/灯管
   → 体积大、占空间
   → 亮度效率不高
   → 已被 LED 背光取代

② LED（发光二极管）背光（当前主流）
   → 体积小、薄
   → 亮度高、效率高
   → 功耗低
   → 当前 LCD 普遍使用

工作原理：
  → LED 提供白色背光光源
  → TFT 薄膜晶体管控制每个像素点的颜色比例
  → 相当于白光经过滤色后呈现出不同的颜色
```

## 三、LCD 模块引脚连接

### 3.1 引脚总览

```
LCD 模块引脚分类：

① 数据总线：D0 ~ D15（16 根）→ FSMC 数据线直连
② 控制信号：
   → CS（片选）→ NE4
   → RS（命令/数据选择）→ A10
   → RD（读使能）→ NOE
   → WR（写使能）→ NWE
   → RST（复位）→ PG15（GPIO）
③ 背光控制：
   → LEDA → 3.3V（背光电源）
   → LEDK → PB0（背光亮度控制，GPIO）
④ 电源：VCC（3.3V）、GND
⑤ 触摸屏（未使用）：X+、X-、Y+、Y-
```

### 3.2 各引脚功能详解

#### ① 数据总线 D0 ~ D15

```
LCD 的 D0 ~ D15 直连 FSMC 的 D[15:0]：
  → 16 位并行数据传输
  → 传输命令码、地址数据、RGB 颜色数据
  → 双向传输（读/写操作）
```

#### ② 片选信号 CS

```
CS 连接 FSMC 的 NE4：
  → 低电平有效
  → 对应 Bank1-4 地址范围：0x6C00_0000 ~ 0x6FFF_FFFF
  → 选中 LCD 模块进行通信
```

#### ③ RS 信号（命令/数据选择）

```
RS 连接 FSMC 的 A10：
  → 这不是真正的地址线功能
  → 而是用于区分命令和数据

RS = 0（A10 = 0）→ 当前传输的是命令（Command）
RS = 1（A10 = 1）→ 当前传输的是数据（Data）

对应的 GPIO 引脚：PJ0

地址映射：
  → 写命令地址：0x6C00_0000（A10 = 0）
  → 写数据地址：0x6C00_0800（A10 = 1，16 位交叉连接下 HADDR[11] = 1）
```

#### ④ 读写控制信号

```
RD（Read）→ 连接 FSMC 的 NOE
  → 读使能，低电平有效
  → 控制从 LCD 读取数据

WR（Write）→ 连接 FSMC 的 NWE
  → 写使能，低电平有效
  → 控制向 LCD 写入数据
```

#### ⑤ 复位信号 RST

```
RST 连接 PG15（通用 GPIO，非 FSMC 复用）：
  → 低电平有效
  → 拉低 → LCD 控制器复位
  → 拉高 → 正常工作
  → 初始化时需要进行复位操作

注意：
  → PG15 没有 FSMC 复用功能
  → 需要单独配置为通用推挽输出模式
```

#### ⑥ 背光控制

```
LEDA（背光阳极）：
  → 直接连接 3.3V 电源
  → 提供背光 LED 的供电

LEDK（背光阴极）：
  → 连接 PB0（LCD_BG，通用 GPIO）
  → 用于调节背光亮度
  → 可通过 PWM 或高低电平控制亮度
  → PB0 没有 FSMC 复用功能
  → 需要单独配置为通用推挽输出模式
```

#### ⑦ 触摸屏引脚（未使用）

```
X+、X-、Y+、Y-：
  → 电阻式触摸屏控制引脚
  → 当前开发板未连接此功能
  → 不需要配置
```

## 五、RS 信号与命令/数据传输机制

### 5.1 为什么只需要 A10

```
LCD 模块没有真正的地址线：
  → 不像 SRAM 那样有 19 根地址引脚
  → 只连接了一根线：A10 → RS

A10 的作用不是寻址，而是区分命令和数据：
  → RS = 0（A10 = 0）→ 传输命令
  → RS = 1（A10 = 1）→ 传输数据

地址和数据都通过 D[15:0] 数据总线传输：
  → 先发命令（告知操作类型）
  → 再发数据（地址参数或颜色数据）
  → 命令和数据分时复用同一组数据线
```

### 5.2 命令/数据传输流程

```
示例：向某个像素点写入红色

① 发送"设置坐标"命令（RS = 0 → 写命令）
   → 告诉 LCD 控制器要操作哪个像素位置

② 发送坐标数据（RS = 1 → 写数据）
   → 传输行地址和列地址
   → 指明要写入的 GRAM 位置

③ 发送"写 GRAM"命令（RS = 0 → 写命令）
   → 告诉 LCD 控制器接下来要写入颜色数据

④ 发送颜色数据（RS = 1 → 写数据）
   → 传输 16 位 RGB565 颜色值（如 0xF800 = 红色）
   → 数据写入 GRAM → 驱动像素显示
```

### 5.3 与 SPI 控制 Flash 的类比

```
控制 W25Q32 Flash（SPI）：
  ① CS 拉低
  ② 发送指令码（如 0x02 页写指令）
  ③ 发送 24 位地址
  ④ 发送数据
  ⑤ CS 拉高

控制 ILI9486 LCD（FSMC）：
  ① FSMC 自动片选（NE4）
  ② RS = 0 → 发送命令码
  ③ RS = 1 → 发送地址/参数数据
  ④ RS = 0 → 发送写 GRAM 命令
  ⑤ RS = 1 → 发送颜色数据

相似之处：
  → 都是先发指令，再发数据
  → 都有命令和数据的区分机制
  → 都通过数据线传输内容

不同之处：
  → Flash 用 SPI（串行），LCD 用 FSMC（并行）
  → Flash 地址通过数据线依次发送，LCD 用 RS 信号区分
  → FSMC 自动管理时序，CPU 负担更轻
```

## 六、地址映射

### 6.1 FSMC 地址空间

```
LCD 连接 NE4 → Bank1-4：
  → 地址范围：0x6C00_0000 ~ 0x6FFF_FFFF

写命令地址：0x6C00_0000（A10 = 0 → RS = 0）
写数据地址：0x6C00_0800（A10 = 1 → RS = 1）

16 位数据宽度下的地址推导：
  → FSMC_A[N] = HADDR[N+1]（交叉连接）
  → A10 = HADDR[11]
  → HADDR[11] = 0 → 地址 = 0x6C00_0000（写命令）
  → HADDR[11] = 1 → 地址 = 0x6C00_0800（写数据）
  → 2^11 = 0x800
```

### 6.2 与扩展 SRAM 的对比

```
扩展 SRAM（NE3）：
  → 地址范围：0x6800_0000 ~ 0x6BFF_FFFF
  → 19 根地址线 → 512K 个存储单元
  → 直接读写数据

控制 LCD（NE4）：
  → 地址范围：0x6C00_0000 ~ 0x6FFF_FFFF
  → 只用 A10 区分命令/数据
  → 先发命令，再发数据
  → 命令中包含操作类型和参数

相同点：
  → 都使用 FSMC 进行地址映射
  → 都在 Bank 1 内
  → 都使用 16 位数据宽度
  → BCR/BTR 配置方式相同
  → GPIO 配置方式相同（复用推挽输出）
```

## 七、LCD 操作的整体流程

### 7.1 初始化流程

```
① 配置 FSMC（BCR + BTR 寄存器或 CubeMX 配置）
② 配置 GPIO（FSMC 复用引脚 + RST/PB0 通用引脚）
③ 复位 LCD（RST 引脚拉低再拉高）
④ 开启背光（PB0 拉高）
⑤ 发送 ILI9486 初始化命令序列
   → 配置显示参数（方向、颜色格式等）
   → 配置电源和时序参数
⑥ 清屏（将所有像素写入黑色/白色）
```

### 7.2 显示字符流程

```
① 设置显示窗口（指定行列范围）
   → 发送设置窗口命令 + 行列坐标数据

② 发送写 GRAM 命令
   → 通知控制器接下来是颜色数据

③ 逐像素写入颜色数据
   → 根据字模数据，像素为 1 写前景色，为 0 写背景色
   → 连续发送 16 位 RGB565 颜色数据
   → GRAM 地址自动递增

④ 完成字符显示
```

## 八、LCD_RST 和 LCD_BG 的 GPIO 配置

### 8.1 RST（复位引脚）

```
引脚：PG15
模式：通用推挽输出
功能：LCD 控制器复位

操作：
  → 初始化时：PG15 输出低电平 → 复位
  → 延时一段时间
  → PG15 输出高电平 → 正常工作
```

### 8.2 BG（背光控制引脚）

```
引脚：PB0
模式：通用推挽输出
功能：控制背光亮度

操作：
  → PB0 输出高电平 → 背光开启
  → PB0 输出低电平 → 背光关闭
  → 可使用 PWM 控制亮度（高级应用）
```

## 九、LCD 背光原理

### 9.1 LED 背光工作方式

```
LED 背光结构：
  → LEDA（阳极）连接 3.3V 电源
  → LEDK（阴极）连接 PB0 控制引脚

亮度控制：
  → PB0 输出低电平 → LED 导通 → 背光亮
  → PB0 输出高电平 → LED 截止 → 背光灭
  → PWM 调节 → 控制 LED 导通时间比例 → 调节亮度

显示原理：
  → LED 发出白色背光
  → 白光穿过液晶层
  → TFT 薄膜晶体管控制每个像素的 RGB 滤光比例
  → 不同比例混合 → 不同颜色
```

## 十一、FSMC 扩展 SRAM vs 控制 LCD 对比

| 对比项 | 扩展 SRAM | 控制 LCD |
|--------|----------|---------|
| NE 信号 | NE3 | NE4 |
| 地址范围 | 0x6800_0000 ~ 0x6BFF_FFFF | 0x6C00_0000 ~ 0x6FFF_FFFF |
| 地址线 | 19 根（A[18:0]） | 1 根（A10 → RS） |
| 数据线 | 16 根 D[15:0] | 16 根 D[15:0] |
| 读写控制 | NOE + NWE | NOE + NWE |
| 额外引脚 | 无 | RST（PG15）、BG（PB0） |
| 操作方式 | 直接读写数据 | 先发命令，再发数据 |
| 存储内容 | 任意数据 | 像素颜色（RGB565） |
| BCR/BTR 配置 | 相同 | 相同 |
| GPIO 配置 | FSMC 复用 | FSMC 复用 + 2 个通用 GPIO |

## 十二、常见问题

| 问题 | 解答 |
|------|------|
| A10 为什么不是地址线功能？ | 连接到 LCD 的 **RS 引脚**，用于区分命令和数据 |
| LCD 有地址线吗？ | **没有**，只有 D[15:0] 数据线，地址通过命令传输 |
| RS = 0 表示什么？ | 传输**命令** |
| RS = 1 表示什么？ | 传输**数据** |
| RST 接哪个引脚？ | **PG15**（通用推挽输出） |
| 背光控制接哪个引脚？ | **PB0**（通用推挽输出），信号名 LCD_BG |
| 为什么用 NE4 不用 NE3？ | NE3 已用于 SRAM 扩展，LCD 用 **NE4** 避免地址冲突 |
| LCD 的地址线只有一根够吗？ | 够了，因为地址通过**命令**传输，不需要独立地址线 |
| FSMC 需要配复用模式吗？ | **不需要**，命令/数据区分通过 RS 实现，非真正的地址复用 |
| CCFL 和 LED 背光的区别？ | CCFL 是荧光管（已淘汰），LED 是发光二极管（当前主流） |
| 触摸屏引脚需要配吗？ | **不需要**，当前未连接触摸屏功能 |
